## Step 0 (shared decisions, made by the orchestrator)

- **Block ids:** 124-131 are reserved for T38a (Portal Door, Swirl blocks, cloth, star stones...). T38b and T38c add no
  blocks. Next free id after wave 13: 132.
- **`WORLD_VERSION`:** T38a sets 18 (the Portal Door changes main-world blocks beside the tower). T38b sets 19 if it
  changes what the `world` / `state` messages carry.
- **Realm id** `swirl` in `REALMS` (`version: 1`). The Dream stays `dream`.
- **Picture Worlds** are data (`PICTURE_WORLDS` in a new `src/pictureworlds.js`, T38a): id, name, emoji, frame colours,
  `ready: false` for every world in wave 13 (a frame whose world does not exist is covered with cloth). Waves 14-15 flip
  `ready` and add a realm.
- **Save fields (all optional, old saves load unchanged):** `stars` (T38a: list of Picture World ids whose Boss you
  beat; always `[]` in wave 13), and whatever T38c adds to the `missions` field (it must keep `{ active, done, last }`
  readable by today's code paths and old saves).
- **Owner not available while this is built:** where a plan has an open question, the planner writes a recommended
  answer, and the orchestrator decides (written down in the plan as "Decided"). The owner can change them later.
- Keep the owner's rules: original names only, short child-friendly text, iPad, no fail states that lose progress.
