### B.5 Travel: Swirl <-> Picture World (`realms.js`)

**Model.** The stash keeps the main world exactly as today (`stash.seed / edits / homes / owner / ret`); a trip one
level deeper adds `stash.up = { id, ret, via, edits }`: the parent realm you came from (`id`, always a realm),
where you come back in it (`ret` = `[x, y, z, yaw, pitch]` in front of the frame you used), which Picture World you
came in by (`via`, a `PICTURE_WORLDS` id: picks the Boss the guide aims at and the frame you return to), and, for a
guest only, a copy of the parent's edits as a fallback (`edits`). Only one level is needed (main -> Swirl -> Picture
World); the code checks `def.parent === game.place` and never names a realm.

Recommended **yes**: the Giant House needs two (toy train, bottle cap on the river), the Pirate Seas one or two

```js
// A path is closed form: { time, loop, at(t) -> { x, y, z, yaw } }, t in seconds (clamped to [0, time], or wrapped when loop).
// Positions are feet positions (you stand at y). yaw faces along the way (player yaw convention: forward = (-sin, -cos)).
export const PATHS = {
  line: ({ points, speed, loop = false }) => path,   // through [[x, y, z], ...] at `speed` blocks/s; loop: back to the first point
  arc: ({ from, to, height, time }) => path,         // a jump from `from` to `to`, top `height` above the higher end
};
export const makePath = spec => PATHS[spec.kind](spec);

export class Mover {
  // run: 'ride' = the clock runs only while someone rides, from 0 at boarding (bottle cap, cannon);
  //      'always' = the clock always runs (a toy train on its loop; you board when it is within `reach`).
  constructor({ path, seat = [0, 0, 0], mesh = null, run = 'ride', reach = 2.5, canLeave = true, onEnd = null })
  clock = 0; rider = null;
  where()          // path.at(clock) + seat (seat turned by yaw) -> { x, y, z, yaw }: the rider's feet
  near(pos)        // horizontal distance from pos to where() (for 'always' boarding and prompts)
  board(player)    // rider = player, player.carry = this, player.vel 0; 'ride': clock = 0. Remembers whether Space was held,
                   // so a held jump key does not throw you off at once (leaving needs a fresh press).
  leave(jump)      // rider.carry = null; jump && canLeave: rider.vel.y = 8.6; rider = null
  update(dt)       // clock += dt (if 'always' or a rider); mesh follows where(); a 'ride' path past its end: the rider
                   // is put at the end (leave(false)), onEnd?.(), clock = 0
```
