# T20 · Treasure blocks you can only mine

Done in one session (size M, no subagents). What was built and why:

## Blocks (`src/blocks.js`)
- Ids **65 Sunstone, 66 Ruby, 67 Sapphire** (`B.SUNSTONE/RUBY/SAPPHIRE`, `TREASURE`), tiles `SUNSTONE/RUBY/SAPPHIRE` after the T19 tiles.
  Textures: a big cut gem on dark rock (sun with rays / red diamond / blue octagon), so they never look like Gold Ore or Star Crystal.
- `glow: true, noLight: true`: they glint in dark caves (drawn with the glow material) but light nothing around them, so the
  cave lighting of old worlds looks the same.
- **Limited blocks:** `limited: true` on a block def + `isLimited(id)`. Only the treasure blocks are limited; all others stay
  unlimited. A future limited block is one more def with `limited: true`.
- All three are in `PLACEABLE` (shown in the Blocks panel always; greyed out at 0).

## World (`src/world.js`)
- Decision: **old worlds get treasure too**, underground only. `placeTreasure(newLandOnly)` turns natural `STONE` into
  treasure, only at least 4 blocks under `world.ground` (never visible on the surface except deep cliff faces):
  - cave walls (stone next to air): 1.5%;
  - stone 8+ blocks down: 0.12%;
  - never inside a gym's / the tower's `protect` box; kind picked by a hash; seed only.
- Runs last in `generateArea` (so the 224 twin and the big map agree: `big-map` unchanged) and after `placeSlotGyms` in
  `generate` for the new land. `generate({ treasure: false })` leaves it out (tests).
- About 250-330 of each kind per map, 200-330 of them visible in cave walls.
- `WORLD_VERSION` 6 -> 7 (blocks changed for the same seed).
- `old-saves`: `SUM` is measured with `treasure: false`; `SUM22` counts treasure as stone. Both numbers are unchanged, which
  proves treasure only ever replaced stone.

## Game (`src/main.js`, `src/ui.js`, `style.css`)
- `game.blockCounts = { [id]: n }`. Breaking a limited block adds 1 (toast "You got a Ruby! You have 3."), placing uses 1;
  with 0, placing does nothing and toasts "You have no Ruby yet. Look for it in cave walls!" (throttled like the gym toast).
- Save field `blockCounts` (optional). `loadCounts` keeps only limited ids with whole counts > 0; old saves start at 0.
  Counts belong to the player (also while visiting a friend's world).
- Hotbar: a limited block's slot shows `×n` and is greyed out at 0. Blocks panel: "Ruby ×3", greyed at 0.
- **Cube farming fix:** a block that has an entry in `world.edits` was placed (or changed) by a player; only natural leaves
  and gold ore (no edit) can give a Capture Cube. Applied to leaves too (same farm).
