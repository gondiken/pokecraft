# T31 · Realms (plan)

Status: draft, waiting on the owner's answers in section 9.

ROADMAP wave 10, T31. A **realm** is a small separate world (own seed-made terrain) that you travel to and back from;
only one place is loaded at a time. Dream (T35) is the first real user; T31 ships the general registry plus one
small test realm, the **Pebble Isle**. The main world never changes (`old-saves` / `big-map` checksums unchanged).

T31 may run beside T32 (map grows), so the logic lives in a new `src/realms.js` and other edits stay small and
marked `// T31`. Expect "keep both" merges in `world.js`, `main.js`, `CLAUDE.md`, `README.md`.

## 0. Today, and what to check first

- `World(seed, scene, materials, [W, D])` already takes a size; `edits`, `applyEdits`, `convertEdits`, `dispose`,
  `cull`, `buildAll` all work for any size.
- `createWorld(seed, edits, size)` (main.js) is the swap point: `riding.stop`, `world.dispose`, generate, edits,

- `snapshot()` saves `game.homeWorld ?? { seed, edits, size, pos, yaw, pitch, time, homes }`; visitors already keep

- Multiplayer `state` = `{ id, name, host, x, y, z, yaw, ride, lead, time, weather }`, `block` = `{ id, x, y, z, b }`.
- `SPAWNS[biome]` is read in three places in creatures.js through `world.biome(x, z)`.
- Before building, check: `homes.reset/load`, protect boxes, `caves.js` light stamping, `guide.js` targets,
  `treasuremap.js`, mission targets, `hideseek.js` `fence`, `npcs.populate`, `weather.reset`, the title fly-over.

## 1. `src/realms.js`: the registry

```js
export const MAIN = 'main';
export const REALMS = {
  pebble: {
    id: 'pebble', name: 'Pebble Isle',
    size: [64, 64],
    seedSalt: 0x5eb1,             // realm seed = realmSeed(mainSeed, salt)
    terrain: 'island',            // key into TERRAINS
    spawns: { island: [/* same rows as SPAWNS[biome] */] },
    gyms: [],                     // realm gyms, each with protect
    look: { sky: 0xb8d8ff, fog: [30, 70], time: null /* null = main clock */, weather: false },
    arrive: [32, 32],
  },
  // dream: T35
};
export function realmSeed(mainSeed, salt) { return Math.imul(mainSeed ^ salt, 2654435761) >>> 0; }
export const TERRAINS = { island(world, def) { /* island in water, trees, the stone home */ } };
export function realmOf(id) { return REALMS[id] ?? null; }
```

- `World` gets an optional `realm`; `generate()` starts with
  `if (this.realm) return TERRAINS[this.realm.terrain](this, this.realm)` (main path untouched).
- `world.biome()` returns the realm's biome; creatures.js reads `spawnTable(world)` =
  `world.realm?.spawns ?? SPAWNS`.
- The Book's "where it lives" line also lists realm names.

## 2. Getting there: the Realm Stone

New block `B.PORTAL`, never generated in the main world.
- **(A, recommended)** placeable, one per world (like the Doormat), saved as a normal edit. Using it asks
  "Travel to Pebble Isle?" via `ui.ask`.
- (B) a live stone (`setLive`) in a spare slot box: fights T32 for slots.
- T35 will enter Dream by sleeping in a Bed (`realms.enter('dream')`), no block needed.
In the realm, a fixed stone near `arrive` takes you home.

## 3. `createRealms(game, { createWorld, save })` -> `game.realms`

- `game.place` = `'main'` or a realm id.
- `enter(id)`: refuse during battle / duel / hide and seek / co-op boss (toast with the reason); store
  `game.realmReturn = { pos, yaw, pitch }` and `game.mainEdits`; show `#loading` "Travelling...", wait a frame,
  `createWorld(seed, edits, size, { realm: def })`; player at `arrive`; `save(true)`; `mp.sendState()`.
- `leave()`: rebuild main with the stashed edits, player back at `realmReturn` (spawn if it collides).
- `createWorld` gains `opts.realm`; `creatures.setWorld` clears wilds, `npcs.populate` only adds realm gym people,
  `homes.reset` hides markers, `weather.reset()` when `look.weather === false`, `findSpawn` uses `arrive`.

## 4. Save format (all optional; old saves load unchanged)

```js
{ ...today's fields (pos = the MAIN-world return spot while in a realm),
  place: 'pebble',                      // missing = 'main'
  realmPos: [x, y, z, yaw, pitch],      // only when place !== 'main'
  realmEdits: { pebble: [[i, b], ...] } // per realm; missing = {}
}
```
- `snapshot()` in a realm: stashed main edits + `realmReturn` as `pos`; current `world.edits` into
  `realmEdits[place]`. `homeWorld` keeps priority (a visitor never saves the host's realm).
- `continueGame`: known `place` -> load the realm at `realmPos`, keep main data stashed; unknown place -> main.
- Cloud saves are the same object; accounts.js unchanged.

## 5. Play together

- `state` gets `place`; an avatar in another place is hidden and not pickable; host time/weather only apply in the
  same place (or when the realm follows the main clock).
- `block` gets `place`, ignored unless it matches.
- Host owns realms: a guest using the stone enters the host's realm; the host sends that realm's edits on the
  `world` event (`{ realm: id }` request). Bump `WORLD_VERSION`.
- Host travelling: guests get a toast ("... went to Pebble Isle. Use the stone to follow."), not forced.
- Joining while the host is in a realm: guest loads main at spawn, toast says where the host is.

## 6. Other features

| Feature | Rule |
| --- | --- |
| Homes | No Doormat in a realm (toast); markers only in main |
| Missions | Main-world targets hidden in a realm; catching/battling still counts |
| Hide and seek | No travel during a game; invite needs the same place |
| Riding | Stops quietly on travel |
| Battles | No travel in battle; losing in a realm wakes you at `arrive` |
| Guide arrow, treasure map | Hidden (or point at the stone) in realms |
| Weather / time | From `look`; fog/sky override `weather.sky()` |
| Caves | None in realms |
| Gym live | `gymLive.reset(world)` gets the realm's gyms only |
| Title fly-over | Always the main world |
