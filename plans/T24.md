3. Pure helper next to `moveInfo`, one random number:
   ```js
   // How many times a multi-hit move hits, from ONE random number r in [0, 1).
   export function multiHits(fx, r) {
     if (fx.weights) {
       let x = r * fx.weights.reduce((a, b) => a + b, 0);
       for (let i = 0; i < fx.weights.length; i++) { x -= fx.weights[i]; if (x < 0) return fx.min + i; }
       return fx.max;
     }
     return fx.min + Math.floor(r * (fx.max - fx.min + 1));
   }
   ```

## 2. Battle rules: `src/battle.js`

### 2a. `mods` default
`{ atk: 0, def: 0, spd: 0, sleep: 0, justWoke: false, flinch: false, healed: 0 }`. `sleep` = turns left (0 = awake); truthy checks keep working. `justWoke` = the free turn. Update the comment above `mods()`.

### 2b. Helpers (after `mods`/`speedOf`)
```js
// Damage taken is multiplied by this (sleeping: +25%). T25's shield multiplies in here too.
takenFactor(c) { return this.mods(c).sleep ? 1.25 : 1; }
// Put a creature to sleep for `turns` of its own moves (2 or 3, drawn by the caller).
async fallAsleep(side, turns) { /* m.sleep = turns; sound 'snooze'; fx status 'sleep'; refresh; say `${who} fell asleep! Zzz` (1300) */ }
// how = 'own' (slept its turns away) or 'bonk' (a multi-hit move's 3rd hit)
async wakeUp(side, how) { /* m.sleep = 0; m.justWoke = true; refresh; say bonk ? `Bonk! The third hit woke ${who} up!` : `${who} woke up!` (1000) */ }
```
`const WAKE_HIT = 3;` at the top. Pull the catch odds out of `throwCube` into `catchChance()` (exactly today's formula, `sleepy = mods(foe).sleep ? 1.5 : 1`).

### 2c. `useMove` start (sleeping)
```js
if (ma.sleep) {
  sound.play('snooze');
  fx?.status('sleep', this.spot(side));
  await this.say(`${who} is fast asleep... Zzz`, 1100);
  ma.sleep--;
  if (!ma.sleep) await this.wakeUp(side, 'own');
  return;
}
ma.justWoke = false; // it is awake and gets to act: its free turn is used up
```
N turns of sleep = exactly N lost moves. `justWoke` cleared only when the creature really moves (after the flinch and sleep checks). No draws on this path.

### 2f. Duel draw order (comment above `useMove`)
hit (1), number of hits (2, multi only), crit (3), damage roll (4), effect chance (5, moves with `chance`), sleep length (6, whenever a sleep effect lands). Status sleep moves use 2 draws; a chance-sleep move that procs uses 5 (4 on a failed roll). Sleeping path and wake-up hit draw nothing. Nothing branches on `side` before a draw.
