# T30.5 · Homes are every type they qualify for (plan)

ROADMAP "T30.5" (owner request, 2026-10-17). Today you pick ONE home type on the Doormat. New rule: **there is no type to
pick; a home is every type it qualifies for, worked out from the blocks.** A gem-studded wooden cabin is cozy AND treasure.
One Doormat, one home, no switching. No world blocks change, so **no `WORLD_VERSION` bump**, no duel `VERSION` bump.

Runs **after wave 9 is merged (T29 in particular)**. T29 moves `count`/`hasBlock`/`atLeast`/`mostly` into `src/features.js`
and `hometypes.js` re-exports them. **Use that result: never redefine a feature helper.** Before starting, check
`src/features.js` exists and `hometypes.js` imports from it. If it does not, stop and tell the orchestrator (T29 is not merged yet).

**Data-driven rule:** outside `hometypes.js` and the `HOME_SPAWN` table, no *logic* may name `'cozy'` or `'treasure'`.
Existing child-facing *texts* of the Cozy Gym in `access.js`/`gyms.js` ("build a cozy home!") may stay: they are the gym's words, not type checks.

## 0. Decisions (owner defaults)

| Question | Decision |
| --- | --- |
| Gem minimum | **15**, one constant `GEMS_NEED` in `hometypes.js`. Everything else reads it from the result (`need`) or the HomeType (`near` text). |
| Where gems count | `where: ['wall', 'floor', 'roof']` (`roof` = the ceiling block of each inside column, from `roomfinder.js` zone `roof`). |
| Stepping on a Doormat with no record (orphan) | It becomes your home at once (`homes.claim`). If you had a home, that old mat turns into Planks ("Your home moved here!"), like placing a new mat. |
| Stepping on your own Doormat the first time after placing it | Opens the panel too (`home.fresh`, not saved). Later visits open nothing (H / E / "My home" as now). |
| Which panel view opens by itself | **`'types'`** ("What can my home be?"): friendliest for a new, empty room. H / E / the meter / "My home" open `'home'` as now. |
| Treasure spawn odds | `HOME_SPAWN.treasure.bonus = { feature: 'gems', step: 40, best: 300 }` -> 1 in `max(300, 1500 - 40 * (gems - 15))`. |
| Old saves | `type` is ignored on load and never written again. No extra toast on load (load re-checks without announcing). |
| Sparkle | Built (about 55 lines in `homeui.js`). If it grows past ~60 lines or costs frames on the iPad, drop it and add a backlog line instead (§6). |

### Contract (the new Home API; nothing else may read a removed field)

```js
// Home (homes.js)
home.report                  // findRoom report (unchanged)
home.results                 // { [typeId]: HomeType.evaluate(report) } for EVERY HOME_TYPES entry
home.types                   // ids whose result is finished, in HOME_TYPES order (e.g. ['cozy', 'treasure'])
home.is(typeId)              // -> boolean (types.includes)
home.resultOf(typeId)        // -> results[typeId] ?? null (progress also for types not finished)
home.finished                // getter: types.length > 0
home.fresh                   // true after place()/claim() until stand() first reports it (not saved, not sent)
home.judge(report)           // sets report, results, types (check() = findRoom + judge; tests fake a report through it)
// REMOVED: home.type, home.homeType, home.result, home.full (use resultOf(id).full)
// HomeManager
homes.ready()                // homes with at least one type (creatures.env.homes)
homes.claim(x, y, z)         // an orphan Doormat becomes your home (-> place(x, y, z, 'claimed')); null if not a free mat
homes.stand(x, y, z, id)     // -> 'orphan' | 'fresh' | false (main.js claims / opens the panel)
// REMOVED: homes.choose(), homes.chooseTarget()
```

## 6. Sparkle on treasure homes (`homeui.js`, about 55 lines)

- A home sparkles when `Object.values(HOME_TYPES).some(t => t.sparkle && home.is(t.id))` and it is within 32 blocks (horizontal) of the
  player and `game.started`. Never a block, never saved or sent.
- Per such home: ONE `THREE.InstancedMesh(SPARK_GEO, SPARK_MAT, 10)` (module-level shared `SPARK_GEO = sparkleGeometry(0.22)` from
  `shapes.js`, `SPARK_MAT = new THREE.MeshBasicMaterial({ color: 0xfff2b0, side: THREE.DoubleSide })`, `frustumCulled = false`), kept in a
  `Map(home -> { mesh, spots, report })`. Never dispose the shared geometry/material; on remove just `scene.remove(mesh)` and `mesh.dispose?.()`.
- Spots (re-made when `home.report` changes): inside cells next to the walls = `report.inside` cells with a 4-neighbour not in
  `inside`; sort by `x * 1000 + z`, take 10 evenly spaced (`cells[Math.floor(i * cells.length / 10)]`), fewer if fewer cells (count = spots).
  Position: cell centre moved 0.42 towards that outside neighbour, `y = report.f + 1.4 + (i * 7 % 3) * 0.7`.
- Twinkle every frame like the creature sparkle (`animateModel`): `period = 1.5 + (i % 3) * 0.3`, `phase = i * 0.37`, lit for 0.45 s of
