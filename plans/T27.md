## 0. Decisions (owner defaults)

| Question | Decision |
| --- | --- |
| View | **First person** stays; camera, hitbox (0.6 x 1.8) and eye (1.62) unchanged. The model is drawn under and in front of the camera, scaled so its back is below the eye; its head shows at the bottom of the screen. No third-person camera. |
| Who | Only a **team** creature with `rideable` and `hp > 0`, tracked by object/uid. Leaves the team or 0 HP -> you get off. |
| How | **Ride / Get off** button on its team card; **R** key; touch **Ride** button. R/touch use the first rideable healthy team creature, or get you off. |
| Land | Walk 7.0 (sprint 9.5) instead of 4.3/6.2; jump 11.2 instead of 8.6 (~2.2 blocks, clears a 2-high wall). In water it swims like on foot. |
| Water | Floats **on the surface** (feet 0.25 below the top, `inWater` false) at 4.3 (sprint 6.2). Space hops (8.6) to climb a bank. On land it stays on but walks at half speed (toast says so). Never dives. |
| Sky | No gravity. Speed 7.5. **Space up 5/s, Shift down 5/s** (touch: Jump becomes "Up" + a "Down" button). Cap = **floor below + 6** (first solid or water block under the column). Above the cap you sink at 4/s. Never below a water floor. |
| Gyms | **While riding, every gym/tower `protect` cell is a wall** (`world.fenced`), toast "Gyms are for walking. Get off to go in!" (max every 2 s). Can't start a ride inside/touching a box. Sky gyms keep their pillar climb. |
| Get off in the air | Sky creature **glides straight down** at 6/s (input ignored), then you get off. Forced get-offs (battle, left the team) are instant: `player.dropToFloor()`. No fall damage exists. |
| Battles | `startBattle` gets you off quietly before `battle.start`. Wild creatures still notice you (everything uses `player.pos`). The ride model is not pickable. |
| Saving | **Not saved.** |
| Visitors | `state` carries `ride: speciesId | null`; the avatar shows that model under the person (raised, legs apart, no swing) and hides its lead. Unknown/non-rideable ids ignored. |
| Sound | `sound.cry(c.species, SPECIES[c.species].type)` on getting on. No new sound ids. |

## 1. New `src/riding.js`
Imports `three`; `SPECIES, nameOf, buildModel, animateModel, disposeModel` (species.js); `TRAITS, hasTrait` (traits.js); `sound`. No main.js import.
```js
// Riding (T27): get on a team creature with the Rideable trait. Physics live in Player (player.ride); this file has the rules,
// the model under the camera, the toasts and the touch button state. Never saved.
export const RIDE = {
  land:  { kind: 'land',  speed: 7.0, sprint: 9.5, jump: 11.2 },
  water: { kind: 'water', speed: 4.3, sprint: 6.2, jump: 8.6, landSlow: 0.5 },
  sky:   { kind: 'sky',   speed: 7.5, climb: 5, sink: 4, cap: 6, glide: 6 },
};
export const rideKind = c => (hasTrait(c, 'rideable') && TRAITS.rideable.species[c.species]) || null;
export const rideSpecies = id => (typeof id === 'string' && TRAITS.rideable.species[id] && SPECIES[id] ? id : null);
export function fitRide(model) {
  const bb = new THREE.Box3().setFromObject(model);           // model at rotation 0 faces +Z
  const h = Math.max(0.3, bb.max.y - bb.min.y);
  const scale = Math.min(1.3, Math.max(0.55, 1.2 / h));
  model.scale.setScalar(scale);
  const shift = Math.min(0.6, Math.max(-0.2, 0.9 - bb.max.z * scale));
  return { scale, shift, lift: -bb.min.y * scale, seat: Math.min(1.2, h * scale) * 0.8 };
}
```

## 2. `src/player.js`
- Constructor: `ride = null; fenceHit = false; capped = false; landed = false;`
- `collides(p)`: `if (this.world.isSolid(x, y, z)) return true; if (this.ride && this.world.fenced(x, y, z)) { this.fenceHit = true; return true; }` (nothing changes without a ride).
- `floorBelow()`: from `floor(pos.y)` down, first solid or `B.WATER` -> `{ y: y + 1, water }`, else `{ y: 0, water: false }`.
- `waterTop()`: `y = floor(pos.y + 0.5)`; if not water try `floor(pos.y - 0.3)`; none -> null; walk up while water (max 64); return `y + 1`.
- `dropToFloor()`: up to 120 x `moveAxis('y', -0.1)` until `onGround` or water floor; `vel.set(0,0,0)`.
- `update(dt)`: keep input code; `r = this.ride`:
  - sky: `return this.fly(dt, wx, wz, len, analog)`.
  - land: speed `(sprint ? r.sprint : r.speed) * analog`, jump `r.jump`; in water the normal swim branch.
  - water: `surf = waterTop()`; on water: speed without 0.55, `target = surf - 0.25`, `vel.y = clamp((target - pos.y) * 8, -4, 4)`, Space and `pos.y > target - 0.3` -> `vel.y = r.jump`; else land physics `* r.landSlow`.
  - no ride: exactly today's code (the `water` spec checks 8.6 / 0.55 / 22 / 10).
- `fly(...)`: reset `capped`/`landed`; `f = floorBelow(), cap = f.y + r.cap`; landing -> `vel = (0, -r.glide, 0)`; else horizontal `w * r.speed * analog`, `vel.y = (Space - Shift) * r.climb`, clamp to cap (`capped = !!Space`), above cap `vel.y = min(vel.y, -r.sink)`; over water never below `f.y`; `moveAxis` x, z, y; `landed` when landing and on ground or at the water floor.

## 3. `src/world.js`
```js
// T27: is this cell inside any gym's or the tower's protected box? Riders can't go in (the box list is fixed after generate()).
fenced(x, y, z) {
  const boxes = this.fenceBoxes ??= [...this.gyms, this.tower].flatMap(g => g?.protect || []);
  for (const b of boxes) if (x >= b.x0 && x <= b.x1 && y >= b.y0 && y <= b.y1 && z >= b.z0 && z <= b.z1) return true;
  return false;
}
```
