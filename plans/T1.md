# T1 · Creature Book: build plan

Goal: a book of all creatures (102 today) that fills in as you play. Seen = picture + name + type.
Caught = the full wiki page. No rewards. Read `ROADMAP.md` "T1" and `CLAUDE.md` first.

Parallel work: T2 (weather) and T5 (final boss) touch main.js, battle.js, ui.js, index.html and style.css
in other worktrees. **Keep edits to those files to the few lines listed below.** All book logic, data
helpers and rendering go in the new `src/book.js`. Add new lines rather than rewriting existing ones.

## 1. Data and save format

- `game.book` is a `Book` (new module). It holds `seen: Set<speciesId>` and `caught: Set<speciesId>`.
  Caught always implies seen.
- Save (`snapshot()` in main.js) gets two new fields: `seen: [...]`, `caught: [...]` (species ids,
  in book order). No Supabase schema change: the save is jsonb and syncs as it does today.
- Loading (`continueGame(saved)`): `seen`/`caught` from the save (missing = `[]`, unknown ids dropped),
  then `syncTeam()` marks every species in `party` and `box` seen and caught. That one call is the
  migration for old saves (v2 without lists, and v1 saves converted by `loadSave()`).
- Book number = position in `Object.keys(SPECIES)` + 1, shown as `#001`. Derived, never saved, so T4's
  new creatures appear on their own.

## 2. Where seen and caught get recorded

| Event | Hook | Records |
| --- | --- | --- |
| New game | `startNew()` in main.js: `game.book.reset(); game.book.syncTeam();` | starter seen + caught |
| Wild battle starts | `Battle.refresh()` in battle.js: `this.game.book?.markSeen(this.foe.species);` | seen |
| Trainer foe sent out | same line (sendOutFoe calls refresh) | seen |
| Duel (player battle) | same line; duel foes are real species | seen (decided: yes) |
| Catch | `throwCube()` caught branch, right after `sound.play('caught')`: `g.book?.markCaught(c.species);` | seen + caught |
| Evolution (battle XP or anywhere) | `snapshot()` calls `game.book.syncTeam()` first; `Book.open()` also calls it | evolved species seen + caught |

`refresh()` is called whenever the foe card changes, so one line covers wild, trainer and duel. It draws
no random numbers, so duels stay in step. `species.js` (`gainXp`) is NOT edited: syncing the team on
every save and every book open is enough (saves happen at every battle end).
Spotting a creature with the crosshair does not count as seen (only battles do); see section 8.

## 3. New module `src/book.js`

```js
import { SPECIES, SPAWNS, MOVES, TYPE_COLORS, effectiveness } from './species.js';
import { portrait } from './ui.js';
import { el } from './util.js';

export const bookOrder = () => Object.keys(SPECIES);            // call at use time, not module load
export const TYPES = () => Object.keys(TYPE_COLORS);
export const BIOME_NAMES = { plains: 'Plains', meadow: 'Flower meadows', forest: 'Forests', swamp: 'Swamps',
  beach: 'Beaches', water: 'Lakes and sea', desert: 'Deserts', mountain: 'Mountains', snow: 'Snowy hills',
  taiga: 'Snowy forests', peak: 'Mountain peaks' };   // unknown keys (e.g. T3 'cave'): capitalise the key
export function spawnInfo(id)      // -> [{ biome, name, when: 'day'|'night'|null, rarity: 'common'|'sometimes'|'rare' }]
                                   //    weight >= 2 common, >= 0.5 sometimes, else rare. Merge duplicates per biome.
export function evolvesFrom(id)    // -> { from, level } | null  (reverse lookup over SPECIES[*].evolve)
export function evolutionChain(id) // -> [{ id, level }]: walk back to the root, then forward; level = level at which
                                   //    this stage evolves into the next (null on the last stage). Guard loops (max 5).
export function typeMatchups(type) // -> { strong: [defTypes with effectiveness(type, d) > 1],
                                   //      weak:   [atkTypes with effectiveness(a, type) > 1],
                                   //      tough:  [atkTypes with 0 < effectiveness(a, type) < 1],
                                   //      immune: [atkTypes with effectiveness(a, type) === 0] }
export function learnList(id)      // -> [{ level, move }] from SPECIES[id].learn, deduped, sorted by level

export class Book {
  constructor(game)                // grabs #book, #book-count, #book-body; this.filter = 'all'; this.page = null
  reset()                          // clears both sets
  load(saved)                      // reset, read saved.seen / saved.caught (keep only ids in SPECIES), syncTeam()
  markSeen(id)                     // no-op for unknown ids; re-render if the book is open
  markCaught(id)                   // adds to both; if new and game.started: game.ui.toast(`${name} was added to your Creature Book!`)
  syncTeam()                       // party + box species -> seen + caught, quietly (no toast)
  toSave()                         // { seen: [...], caught: [...] } in book order
  counts()                         // { seen, caught, total }
  get isOpen()
  open()                           // syncTeam(); render list (or the open detail page); show #book
  close()                          // hide #book
  showList() / showDetail(id)      // render into #book-body
}
```
`markSeen` is called on every `refresh()`: make it a cheap `Set.has` check first.

  Under the row, for a type filter: `Fire: 4 seen · 2 caught (of 6)`.

## 9. Decisions to confirm with the owner (defaults chosen)
1. Seen only through battles (wild, trainer, player battles), not by pointing at a creature. Default: battles.
2. Evolution chain hides names of unseen stages (`???` + silhouette) so the book keeps surprises. Default: hide.
3. Seen-but-not-caught pages show picture, name and type only. Default: yes.
4. A toast "X was added to your Creature Book!" on the first catch of each species. Default: on.
5. Type filter shows unseen silhouettes of that type (a goal: "2 fire ones left"). Default: yes.

## 10. Risks

  `ui.js` `renderHud` is T5's area; this task only touches `portrait`, the constructor and the panel methods.
- Portrait cost: up to ~200 offscreen renders on first open; batched with setTimeout so the UI stays responsive.
- `refresh()` runs often in battles; `markSeen` must be cheap and not re-render a closed book.
