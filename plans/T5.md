# T5 · Final boss: the Champion's Tower (plan)

Goal: after all 16 badges, a **Champion's Tower** near the middle of every map opens. Two guards,
then **Champion Solenne** with 6 creatures (Lv 40–45), the last one a one-of-a-kind legendary,
**Zenithar**, that powers up at half HP. Winning is saved, shows a "Champion" title on the HUD, and
the champion can be re-battled. A Coach in the tower (double XP) and wild creatures that grow
stronger after 16 badges close the level gap. Everything original; text short and child-friendly.

Parallel work: T1 (Book) and T2 (Weather) also edit `main.js`, `battle.js`, `ui.js`, `creatures.js`,
`sound.js`, `style.css`. Keep every edit to those files to **small, separate blocks / new lines**
(never reformat existing lines). New logic lives in `gyms.js` (data) and `world.js` (building).

## Design decisions (defaults; see "Ask the owner")
- **Unlock:** the door is always open (no saved door state). Guards, Coach and Champion refuse
  politely until `badges.length === 16`. Nurse heals anyone.
- **Order:** Guard Bram → Guard Opal → Champion Solenne. Guards stay beaten (`beaten` list).
  Losing to the champion sends you home like any loss (+ a hint toast); guards stay beaten.
- **Levels:** Guard Bram 34–36, Guard Opal 36–38, Champion 40–43 + Zenithar 45. Rematch: +3 levels.
- **Level gap:** (a) **Coach Dex** in the tower: unlimited battles, 3 creatures at your strongest
  creature's level (min 25, max 44), **double XP**, +1 Capture Cube. (b) After 16 badges, wild
  creatures get **+10 levels** (cap 50). Before 16 badges nothing changes.
- **Legendary:** add `zenithar` to `SPECIES` with `legendary: true`, its own body shape
  (`guardian`), not in `SPAWNS`, not catchable (trainer battles already disable Cubes). The
  roster spec is changed to skip `legendary` species in its per-type counts and "can be found"
  check (see Tests). This keeps "6 per type" (and T4's later "7 per type") true for normal species.
- **Boss feel:** 3-line story intro; boss battle starts with a low motif and a very quiet looping
  tune; Zenithar "powers up" at ≤ 50% HP (attack ×1.25, golden glow, log lines). It cannot be
  knocked out in one hit from above half HP (it hangs on at 1 HP and powers up), so every player
  sees the moment. Win: fanfare, confetti overlay, +20 Cubes, "★ Champion ★" on the HUD.

## 3. World — `src/world.js` (import `TOWER` next to `GYMS`)
- Constructor: `this.tower = null;`. `generate()`: call `this.placeTower();` right **after**
  `this.placeGyms();`. Do **not** change `gymSpots`, `placeGyms` or `buildGym` (gym positions and
  buildings must stay identical in existing saves).
- `towerSpot()`: nearest valid spot to the middle, deterministic from the seed, own hash streams:
  ```js
  const cx = WORLD_W / 2, cz = WORLD_D / 2, off = hash2(3, 77, this.seed) * Math.PI * 2;
  const clear = (x, z, gap) => this.gyms.every(g => Math.max(Math.abs(x - g.x), Math.abs(z - g.z)) >= gap);
  const dry = (x, z) => [[0, 0], [6, 6], [-6, 6], [6, -6], [-6, -6]].every(([dx, dz]) => this.terrainHeight(x + dx, z + dz) > WATER_LEVEL);
  for (const gap of [26, 23]) for (const needDry of [true, false])
    for (let r = 18; r <= 80; r += 2) for (let k = 0; k < 24; k++) {
      const a = off + k * Math.PI / 12, x = Math.floor(cx + Math.cos(a) * r), z = Math.floor(cz + Math.sin(a) * r);
      if (x < 18 || z < 18 || x >= WORLD_W - 18 || z >= WORLD_D - 18) continue;
      if (clear(x, z, gap) && (!needDry || dry(x, z))) return [x, z];
    }
  // Last resort (never expected): the grid spot furthest from every gym.
  ```
  gap 23 = gym building (R+2 = 8) + tower slope (R+9 = 15): the tower never touches a gym building
  or its door path. r ≥ 18 keeps the tower (incl. plaza, ≤ 8) away from the start point area.
- `placeTower()`: `[x, z] = this.towerSpot()`; `front` faces the middle exactly like `placeGyms`;
  `floor = Math.max(WATER_LEVEL + 1, Math.min(this.terrainHeight(x, z), 24))`;
  `this.buildTower(x, floor, z, front)`; then
  `side = [front[1], front[0]]`, `posOf = ([d, s]) => [x + front[0] * d + side[0] * s + 0.5, floor + 1, z + front[1] * d + side[1] * s + 0.5]`,
  `this.tower = { def: TOWER, tower: true, x, z, y: floor + 1, front, people: TOWER.people.map(p => ({ ...p, pos: posOf(p.at) })) }`.
- `towerAt(x, z)`: like `gymAt` (|x − t.x − 0.5| ≤ 6.5 and same for z), else `null`.
- `buildTower(x0, fy, z0, front)` (R = 6; write it standalone, copying the plant-clearing and
  ground-sloping loops from `buildGym`, all `set(..., false)`):
  1. Clear plants within R+5; slope ground within R+9 (copy).
  2. For |dx|,|dz| ≤ R+2: stone foundation below `fy`, air above. Outside the walls (R+1..R+2):
     `STONE_BRICKS` plaza at `fy`.
  3. Inside (≤ R): floor `PLANKS`; a 1-wide `WOOL.rainbow` carpet along the door axis from the door
     to d = −4, and a 3×3 `WOOL.rainbow` square centred on the champion (d = −4, s = 0).
  4. Walls (edge cells) from fy+1 to fy+11 in `STONE_BRICKS`; corners rise to fy+14 with a `LAMP`
     at fy+15. Windows: `GLASS` where the along-wall coordinate is ±3 and y ∈ {fy+3, fy+4, fy+7,
     fy+8}. A `LAMP` set into each wall at along-wall 0, y = fy+6 (not over the door).
  5. Roof: fy+12 all of ≤ R in `WOOL.rainbow`; fy+13 battlements on the edge where (dx+dz) is even
     (`STONE_BRICKS`) and rainbow wool for ≤ R−2; fy+14 rainbow wool for ≤ R−4; fy+15..fy+17
     `CRYSTAL` spire at the centre (glowing beacon; max height 24+17 = 41 < WORLD_H 48).
  6. Door 3 wide × 4 tall (fy+1..fy+4) in the front wall; `STONE_BRICKS` path to d = R+4.
     Beside the door (d = R+1, s = ±2): `WOOL.rainbow` pillars fy+1..fy+4 with a `LAMP` on top.
  7. Two `CRYSTAL` columns (2 tall) at d = −5, s = ±2 beside the champion. Nothing else inside.
  No new block types; floor/plaza blocks are not in `creatures.js` `GROUND`, so nothing spawns there.
