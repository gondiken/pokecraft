# T34 · Squad: a new type and its gym (plan)

Read first: `CLAUDE.md`, `ROADMAP.md` ("Wave 11", "T34 · Squad"), `plans/wave11.md` (shared decisions), and as models
`plans/T21.md` (Cozy/Treasure: the closest one) and `plans/T19.md` (slot gyms). Step 0 of the wave is on the branch already:
`TYPE_COLORS.squad`, the chart row/column, `WOOL.squad` = **80**. Do not touch them (except the optional wool pattern, §8).

**Owner's design (ROADMAP):** lots of little ones making one big one, like "three kids in a trench coat". Every family has
its own crew member and its own stack; evolving = a taller stack with more members. One **general** optional species field
`weakensWithHp`: attack power shrinks with HP, so multi-hit moves are great against it. Members fall off from the top as it
gets hurt. A plain gym building in slot 6 with tiered trainer spots (a human pyramid you take apart one battle at a time).

**Result:** 7 Squad species (3 two-stage families + a single 7th), 4 new body shapes built on one shared `crewStack` helper,
6 new moves (4 type moves + 2 signature moves), 3 big moves, `weakensWithHp` + `CREW` + `hpPower`/`crewHit` +
`setModelHealth` (all generic), the tumble in `animateModel`, the **Big Top Gym** (Pyramid Badge) in south slot 6,
`duel.js` `VERSION` 9 -> **10**, `WORLD_VERSION` 12 -> **13**. No new block ids, no new save field, no live gym parts.

**Type emoji (docs only):** 🤝 (the gym: 🎪).

**Files (yours):** new `src/bigtop.js`, new `tests/specs/squad.mjs`, `battle.js` (the `weakensWithHp` hooks and the health

## 0. Facts the design relies on (checked in the code)

- `Battle.refresh()` (battle.js ~225) is the one place that redraws both HP bars (`card()`); it runs after every hit, heal,
  switch, faint, XP and gift. Battle models are built in `placeAlly` (~299), `placeFriend` (~329), `sendOutFoe` (~364),
  `sendOutGiant` (~401); a wild foe uses `wild.model` (set in `start()`, ~477). `evolveAnimation` calls `placeAlly(true)`.
- Models are animated every frame: battle ally/friend/trainer foe by `main.js` `frame()` (`animateModel(m, now / 1000, false)`,
  lines ~1062-1064; a duel and a co-op battle have `battle.trainer`, so their foe is animated too), wild creatures (also
  while `frozen` in battle) by `creatures.js` (`animateModel(w.model, w.t, ...)`). Each model always gets the same clock.
- Damage is computed in `useMove` (~934-946): `atkPower = as.atk * stage(ma.atk) * (atk.boost || 1)`, `base = floor(...)`,
  `dmgNow = max(1, floor(base * stab * eff * crit * mult * field * takenFactor(def) * roll))`, applied once per hit of a
  multi-hit move. `backfire` (~993) has its own `selfBase`. Duel draw order (comment above `useMove`) must not change.
- `Box3.setFromObject` counts invisible meshes too (three r160 does not look at `visible`).
- Generic flags are read from `SPECIES[id]` (`legendary`, `disguise`, `floats`); the Treasure sparkle is the one place that
  checks a type (`if (sp.type === 'treasure')` in `buildModel`): **do not copy that**. Nothing in this plan checks `'squad'`.
- `placeSlotGyms([T17_SLOTS, Infinity])` places slots 5+ in the 368 layer of `World.generate()`; `SLOT_BUILDERS` in
  gymplace.js maps `def.build` to `(world, def, slot) => gym`; `slot.box` is +-24 (`SLOT_R`) around the slot centre, all y.
  `levelSite(rect, fy, box, pad)` levels and slopes (reach = pad + 9 outside rect). Model builder: `src/clocktower.js`
  (guarded `put`, `cell(d, s)`, `front`/`side`, returned gym object). NPCs read `leaderPos`, `leaderHeading`,
  `trainerPositions`, `trainerHeadings` (npc.js `populate`); `talkTo` (main.js ~723) makes the leader wait for both trainers.
- `roster` checks every key of `TYPE_COLORS` has 7 species: until T33/T35/T36 are merged it fails for food/dream/parkour.

### 2.1 The shared helper (the "stack shape builder")
```js
// T34: a crew of little ones standing on each other's shoulders. spots = [[x, y, z], ...] from the BOTTOM up; make(g, i)
// builds member i into its own group g (at its spot). Fills parts.members, which setModelHealth / animateModel use: a member
// is { g, base, side, on, fallAt }. g is ONLY moved by the health code (rest position = base); put any idle sway on a pivot
// INSIDE g, never on g itself.
function crewStack(root, parts, spots, make) {
  const body = pivot(root, 0, 0, 0);
  parts.members = [];
  spots.forEach(([x, y, z], i) => {
    const g = pivot(body, x, y, z);
    make(g, i);
    parts.members.push({ g, base: g.position.clone(), side: i % 2 ? 1 : -1, on: true, fallAt: null });
  });
  return body;
}
```
Members are siblings (not nested), so hiding one never hides another. Legs of the **bottom** member(s) go in `parts.legs`
(walking), the **top** member's waving arm in `parts.arms`, its head in `parts.head`. Every member has `eyes(...)`. Every
shape needs an idle animation (`swing` on inner pivots), stands on y = 0, faces +Z, and after scale is at most 2.6 high and
2.6 wide (the `seventh` spec rule, checked for all 7 in §9).

## 3. `weakensWithHp` (battle rule, generic)

### 3.1 Data and helpers (species.js, right after `statsFor`; one block, commented `// T34`)
```js
// T34: crews (species with `weakensWithHp: true`, read like `legendary`/`disguise`, never a type check). Their attack power
// shrinks with their HP: x1 at full, x0.8 at half, x0.6 at the very end. Moves that hit many times knock more of them off: x1.2.
export const CREW = { floor: 0.6, multi: 1.2, book: 'A crew of little ones! It gets weaker as it gets hurt, and moves that hit many times knock more of them off.' };
export function hpPower(c) {
  if (!SPECIES[c.species]?.weakensWithHp) return 1;
  const f = Math.max(0, Math.min(1, c.hp / statsFor(c).maxHp));
  return CREW.floor + (1 - CREW.floor) * f;
}
export const crewHit = (c, mv) => (SPECIES[c.species]?.weakensWithHp && mv.fx?.kind === 'multi' ? CREW.multi : 1);
```
Gentle and fair: at half HP a crew hits like it has 80% attack; a squad species' base attack is about 10-15% higher than a
normal one's to make up for it. Multi-hit moves (High Fives, Rapid Click, Pillow Fight, Gem Toss... and Count Off!) do x1.2
per hit against a crew, so "multi-hit moves are great against it" is true and the Book can say it.

### 3.2 Where it applies (battle.js; no new draws, nothing branches on `side`)
- `useMove`: `const atkPower = as.atk * stage(ma.atk) * (atk.boost || 1) * hpPower(atk), ...` (the attacker's HP at the
  moment it attacks; it does not change during its own multi-hit), and in `dmgNow` add `* crewHit(def, mv)` after `eff`.
- `backfire`: the same `* hpPower(atk)` in `selfBase` (a risky move is "attack power" too).
- `pickFoeMove` (AI only, `Math.random`, never in a duel): multiply the damage score by `crewHit(ally, mv)`.
- Import `hpPower, crewHit` from species.js.

**Duel safety:** both browsers have identical full-HP copies, identical draws and identical HP after every hit, and these
are plain arithmetic on that state, so both compute the same numbers. The rule changes damage, so **`duel.js` `VERSION`
9 -> 10** (comment: `10: T34 crews (weakensWithHp: attack shrinks with HP, multi-hit x1.2 against them)`). An older game is
told it is older (existing code). Co-op giants are not crews (`makeBoss` species never have the flag), nothing to do.

## 4. Members you can see: `setModelHealth` + tumble

### 4.1 `setModelHealth` (species.js, next to `tintModel`)
```js
// T34: shows a crew's members for its health: frac = hp / maxHp. Members drop off from the TOP; one is always left (also at
// 0 HP: the faint animation shrinks it). instant: hide at once (a model just built); else animateModel tumbles them off.
// A model without parts.members (every non-crew creature) is left alone.
export function setModelHealth(group, frac, { instant = false } = {}) {
  const p = group?.userData?.parts, list = p?.members;
  if (!list?.length) return;
  const n = list.length;
  const on = frac > 0 ? Math.min(n, Math.max(1, Math.ceil(frac * n - 1e-9))) : 1; // 1e-9: 2/3 * 3 must give 2
  p.membersOn = on;
  list.forEach((m, i) => {
    const want = i < on;
    if (want === m.on) return;
    m.on = want;
    m.fallAt = null;
    if (want || instant) { m.g.position.copy(m.base); m.g.rotation.set(0, 0, 0); m.g.visible = want; }
  });
  if (on > 1) list[0].g.rotation.z = 0; // no more nervous shaking
}
```
Healing back up shows members again at once (no animation). Export it from species.js.

### 4.2 Tumble in `animateModel` (one loop, time-based like the sparkle)
```js
// T34 crews: a member that lost its place tumbles off sideways (FALL_TIME s), then hides. The last one left shakes nervously.
for (const m of p.members || []) {
  if (m.on || !m.g.visible) continue;
  if (m.fallAt == null || t < m.fallAt) m.fallAt = t;
  const k = (t - m.fallAt) / FALL_TIME;
  if (k >= 1) { m.g.visible = false; m.g.position.copy(m.base); m.g.rotation.set(0, 0, 0); continue; }
  m.g.position.set(m.base.x + m.side * k * 0.7, m.base.y * (1 - k * k) + Math.sin(k * Math.PI) * 0.25, m.base.z + k * 0.2);
  m.g.rotation.z = -m.side * k * 2.5;
}
if (p.members?.length > 1 && p.membersOn === 1) p.members[0].g.rotation.z = Math.sin(t * 24) * 0.06;
```
with `const FALL_TIME = 0.7;` next to `SPARKLES`. Put the loop before the last line of `animateModel`.

### 4.3 Where it is called (battle.js only)
Remember which creature a model shows: wherever a battle model is set, also set `model.userData.who = <creature>`:
`placeAlly` (`this.ally`), `placeFriend` (`this.friend`), `sendOutFoe` and `sendOutGiant` (`this.foe`), and in `start()` for a
wild foe (`wild.model.userData.who = wild.data`). Then:
- Right after each of those (model built, before its grow tween): `setModelHealth(model, c.hp / statsFor(c).maxHp, { instant: true })`.
  This covers switching in (a hurt bench creature), sending out the next trainer creature, the gift arrival and evolving
  (`evolveAnimation` -> `placeAlly(true)`), and a wild crew you ran from earlier (it is still hurt, so members stay off).
- At the end of `refresh()`:
  ```js
  // T34: crews show their health (generic: a no-op for models without members)
  for (const [m, c] of [[this.allyModel, this.ally], [this.foeModel, this.foe], [this.friendModel, this.friend]]) {
    if (m && c && m.userData.who === c) setModelHealth(m, c.hp / statsFor(c).maxHp);
  }
  ```
  The `who` check matters: `turn()` switches `allyIdx` and calls `refresh()` before `placeAlly` builds the new model.
  `refresh()` runs after every hit (each hit of a multi-hit knocks members off one by one), heal, recoil, backfire,
  gift, both sides, wild, trainer, duel and co-op. Specs that stub `b.refresh = () => {}` are unaffected.
- `spot(side)`: when `m.userData.parts?.members` exists, build the box from the visible members only
  (`for (const mm of members) if (mm.g.visible) box.expandByObject(mm.g)`), so effects aim at what is left of the stack.
  Other models keep `setFromObject`.

**Outside battles nothing changes:** portraits (`ui.js`), the Book, riding, a friend's lead creature and fresh wild spawns
build a fresh model with every member on. So a caught crew shows all members in your team and in the Book, and a party
crew sent into battle shows members for its current HP (all of them at full HP).
