Owner's design: ROADMAP "Waves 7 and 8", T22 (owner-approved; read it first). This plan builds on **T21 as planned in
`plans/T21.md`** (being built in parallel): T21 adds the `home:<type>` spawn condition, `HOME_SPAWN` / `HOME_RANGE` in
`spawnrules.js`, the `place` hunk in `creatures.trySpawn`, wool ids 68/69, and expects
`creatures.env.homes()` = finished homes `{ type, x, y, z, full, spawnSpot() }`. **T22 starts after T21 is merged.**

finder + `Home` + `HomeManager`, `hometypes.js` data, `homeui.js` meter/glow/chooser/preview), an `onEdit` hook in

Nothing in the meter, glow, preview, chooser or spawning knows "cozy" or "treasure": they read a `HomeType` and its
`evaluate()` result. A test adds a third type with `addHomeType()` and nothing else.

## 2. The room finder (`src/homes.js`, `findRoom(world, x, y, z)`; knows no home type)

Everything is checked in **columns** around the Doormat at `(mx, f, mz)` (`f` = the mat's y = floor level). Layers:
`L1 = f+1`, `L2 = f+2`, `L3 = f+3`. `solid(x,y,z)` = `isSolid(world.get(...))` (glass, leaves count as solid; the
caller passes virtual plugs, see step 3). A door is **1-2 wide, 2 high, with a block above it** (§12 Q4), walls are at
least 3 high (L1-L3), so the roof is at `f+4` or higher.

1. **Start.** If `L3` above the mat is open, start at the mat column. If it is solid (the mat lies in the doorway, under
   the lintel), try its 4 neighbours with `L3` open; use the first whose flood (step 2) does not escape, else the first.
   None -> report `{ found: false }` (mat buried in a wall).
2. **Inside = 4-neighbour flood over columns whose `L3` cell is open.** Track the bounding box; if it would get wider
   or deeper than **20** -> stop, `escaped = true`. Furniture up to 2 high (bed, fireplace, lamp, rug) never blocks the
   flood; a 3-high pillar inside is just a pillar. The door's lintel keeps the flood in.
3. **Leak finder (only when escaped; at most 4 rounds).** Walk the BFS parent chain from the mat to the first column
   that went past 20; on it, take the first column `c` (from the mat outwards) that is a **neck**: along the axis
   perpendicular to the step into `c`, `L3`-solid columns on both sides with at most 3 open columns between them
   (counting `c`). Plug `c` virtually at `L3`, add `[c.x, f+3, c.z]` to `holes.wall`, and flood again. Still escaped
   after 4 plugs, or no neck on the path -> stop with `escaped = true` (walls not closed, or the room is bigger than
   20x20, or the mat is outside the house); size/roof/floor are then `null` ("?" on the meter).
4. **Ring** = every 8-neighbour of an inside column that is not inside. For each ring column:
   - `L3` open (only possible diagonally: a missing corner) -> holes at its open cells L1-L3.
   - `L1` and `L2` both solid -> wall.
   - both open -> **door-like** if it is 4-adjacent to an inside column, else holes at both cells.
   - one open -> hole at that cell.
   Door-like columns group into 4-connected runs. Runs of 1-2 are door candidates; **the door is the candidate nearest
   the mat**; every other run (and runs of 3+) adds its L1/L2 cells to `holes.wall`. `doorRuns` = number of runs.
5. **Roof:** for each inside column, `roofY` = the lowest solid y in `[f+4, min(f+12, WORLD_H-1)]`, or none. Columns
   without one -> `holes.roof` at `(x, roofLevel, z)`, where `roofLevel` = the most common `roofY` (or `f+4` if no column
   has a roof).
6. **Floor:** inside columns where `(x, f, z)` is not solid -> `holes.floor`.
7. **Size:** `size = [w, d]` of the inside columns' bounding box, door columns left out. `'small'` if `w < 8 || d < 8`.
8. **Zones** (for features), counted as `counts[zone][id]` plus `wallTotal`: `floor` = inside columns at `f` (the mat
   included); `inside` = non-air cells of inside columns from `f+1` to `roofY-1`; `wall` = non-air cells of ring
   columns from `f+1` to `max(f+3, roofLevel-1)`; `roof` = the `roofY` block of each inside column.

Report (plain object, also what tests read):
```js
{ found, mat: [mx, f, mz], f, escaped, inside: [[x, z], ...], box: { x0, x1, z0, z1 }, size: [w, d] | null,
  door: [[x, z], ...] | null, doorRuns, roofLevel,
  holes: { wall: [[x, y, z]], roof: [...], floor: [...] },
  counts: { floor: { [id]: n }, inside: {...}, wall: {...}, roof: {...} }, wallTotal,
  checks: { walls: bool, roof: bool | null, size: 'ok' | 'small' | null, floor: bool | null },
  ok }   // ok = walls && roof && size === 'ok' && floor
```
`checks.walls = found && !escaped && !holes.wall.length && !!door`.

Cost: at most ~450 flood columns x ~12 block reads, x5 with leak rounds: well under 1 ms. It only runs when needed (§4).

## 3. Home types (`src/hometypes.js`, data)

```js
// A Feature is a small check with a picture: { key, name, icon (block id for the picture), check(report) -> { done, have, need } }.
export const hasBlock = (id, { key, name, where = ['inside'], icon = id }) => ...        // 1 of id in the zones
export const atLeast  = (n, ids, { key, name, where, icon = ids[0] }) => ...            // n of these ids in the zones
export const mostly   = (ids, share, { key, name, where = ['wall'], icon = ids[0] }) => ... // need = ceil(total * share), total > 0
export class HomeType {
  constructor({ id, name, blurb, creature, rule = null, features, need = features.length, show = 'hearts',
                example, spawn, gymMovesIn = null }) { ... }
  // -> { room: report.checks, ok, rule: { key, name, icon, done, have, need } | null,
  //      features: [{ key, name, icon, done, have, need }], done, need, show, finished, full }
  evaluate(report) { ... }  // finished = report.ok && (!rule || rule.done) && done >= need; full = finished && done === features.length
}
export const HOME_TYPES = {};                     // registry, in chooser order
export function addHomeType(t) { HOME_TYPES[t.id] = t; HOME_SPAWN[t.id] ??= t.spawn; return t; }
export function removeHomeType(id) { ... }        // tests clean up
```
`count(report, zones, ids)` sums `report.counts[zone][id]`. `show: 'hearts'` = one heart per feature; `'counter'` = the
features' `have/need` as "6/10".

```js
const WOOD = [B.PLANKS, B.LOG, B.PINE_LOG], WOOLS = Object.values(WOOL);
addHomeType(new HomeType({
  id: 'cozy', name: 'Cozy home', creature: 'cozy', blurb: 'Soft and warm. Cozy creatures come to visit.',
  rule: mostly(WOOD, 0.5, { key: 'wood', name: 'Wooden walls', icon: B.PLANKS }),
  features: [
    hasBlock(B.BED, { key: 'bed', name: 'Bed' }),
    hasBlock(B.FIREPLACE, { key: 'fire', name: 'Fireplace', where: ['inside', 'wall'] }),
    atLeast(4, WOOLS, { key: 'rug', name: 'Rug', icon: WOOL.cozy, where: ['floor', 'inside'] }),
    hasBlock(B.LAMP, { key: 'lamp', name: 'Lamp', where: ['inside', 'wall', 'roof'] }),
    atLeast(2, [B.GLASS], { key: 'windows', name: 'Windows', where: ['wall'] }),
  ],
  need: 3, show: 'hearts', example: COZY_EXAMPLE, spawn: HOME_SPAWN.cozy, gymMovesIn: 'cozy', // T23 uses gymMovesIn
}));
addHomeType(new HomeType({
  id: 'treasure', name: 'Treasure home', creature: 'treasure', blurb: 'Gems in the walls. Treasure creatures may visit (rarely!).',
  features: [atLeast(10, TREASURE, { key: 'gems', name: 'Gems', icon: B.SUNSTONE, where: ['wall', 'floor'] })],
  need: 1, show: 'counter', example: TREASURE_EXAMPLE, spawn: HOME_SPAWN.treasure,
}));
```
**Examples** (block lists, local coordinates, floor at y = 0): `boxHouse({ w, d, h = 3, wall, corner = wall, roof,
floor, door = 1 })` returns `{ mat: [x, 0, z], blocks: [[x, y, z, id, tag]] }` (floor tag `floor`, walls `walls`,
roof `roof`, the mat inside the door). Tags name the room checks (`walls`, `roof`, `floor`) or a feature/rule `key`.
- `COZY_EXAMPLE`: 10x10 outside (8x8 floor), planks walls (`wood`), log corners, 1-wide door in the middle of the front,
  planks roof at y = 4 with a log rim; a Bed in a back corner (`bed`), a Fireplace in the back wall (`fire`), a 2x2
  Cozy Wool rug in the middle of the floor (`rug`), a Lamp in the roof (`lamp`), 2 glass blocks in the side walls at
  y = 2 (`windows`).
- `TREASURE_EXAMPLE`: 10x10 stone-brick house, 10 gems (4 Sunstone, 3 Ruby, 3 Sapphire) in the walls at y = 1-3 and
  2 in the floor, tag `gems`.
`export function placeExample(world, type, x, y, z)` writes an example with `world.set` (spec helper; never called by the game).

## 4. Homes in the world (`src/homes.js`: `Home`, `HomeManager`)

**Ownership.** A home is a record `{ owner, name, x, y, z, type }` (`type` = a `HOME_TYPES` id or null until chosen).
`owner` = `game.playerId`: a random id made once and saved (`saved.playerId || game.playerId || randomId()`), so it is
the same on every device with the same online save. **Homes belong to the world**: the world's save (the host's) keeps
every home in it, also a visitor's. One home per owner per world.

```js
export class Home {           // knows nothing about types beyond calling type.evaluate
  owner; name; x; y; z; type; report = null; result = null;
  get homeType() { return HOME_TYPES[this.type] ?? null; }
  get finished() { return !!this.result?.finished; }  get full() { return !!this.result?.full; }
  check(world) { this.report = findRoom(world, this.x, this.y, this.z); this.result = this.homeType?.evaluate(this.report) ?? null; }
  freeCells() { ... }   // inside columns (not the mat, not the door) with a solid floor and air at L1, L2: [{ x, y: f+1, z }]
  spawnSpot() { ... }   // a random free cell (not the player's), or null   (T21's interface)
  standSpots(n) { ... } // n free cells, furthest from the door first (T23: where the leader and assistant stand)
  toSave() { return { owner, name, x, y, z, type }; }
}
export class HomeManager {
  constructor(game)
  reset(world)                  // a new world: no homes, hooks world.onEdit
  load(records, worldOwner)     // validates (below), checks every home once
  toSave()                      // records of this world's homes
  list; worldOwner; active; onMat; checks (a counter, for tests)
  mine()  at(x, y, z)  worldOwnerHome()  ready()        // ready() = finished homes (creatures.env.homes)
  place(x, y, z)                // you placed a Doormat: your home moves here (old mat -> Planks, sent as a block edit), sent as 'home'
  choose(home | [x, y, z], type)// type picked on a mat: claims an orphan mat; only the owner changes an owned home; sent
  apply(record)                 // a 'home' message: replaces that owner's record (or a record at that spot)
  onEdit(x, y, z, old, id)      // from World.set: a Doormat gone -> its home is gone; marks homes whose box holds the cell dirty
  update(dt, pos)               // re-checks dirty homes (at most every 0.25 s), fires change events, ends `active` > 24 blocks away
  stand(x, y, z, id)            // every frame on the ground: entering a mat -> active = its home (chooser if type null)
  onChange(fn)                  // fn(home, what): 'placed' | 'moved' | 'removed' | 'type' | 'finished' | 'unfinished'
}
export { findRoom };
```
- **`World.set`** (record branch only, after `markDirty`): `this.onEdit?.(x, y, z, old, id);`. Remote `block` messages
  go through `set`, so everyone notices a broken Doormat or a changed wall the same way. A home's box is
  `|dx| <= 23, |dz| <= 23, f-1 <= y <= f+13`. Re-checks happen only on edits in that box (plus once on load and on
  `choose`), never every frame.
- **Placing a second Doormat** (`place`): your old mat turns into **Planks** (`world.set` + `mp.sendBlock`; §12 Q1),
  toast "Your home moved here!". **Breaking a Doormat** (anyone; §12 Q5): the home is removed; its owner gets
  "No doormat, no home! Put a Doormat down to make a home." An **orphan** mat (a Doormat with no record, e.g. lost
  message) is nobody's: standing on it opens the chooser and choosing claims it.
- **First time on a new mat** (`stand`, on entering a mat whose home has `type === null` and is yours or an orphan,
  while `playing()`): `game.openHome('choose')`. Leaving without choosing is fine; it asks again next time.
- **Change type any time:** on the mat press **H** (desktop; also **E** when nothing is targeted) or tap the meter /
  the **My home** action button (touch) -> home panel -> "Change home type" (only for your own home).
- **`active`** (whose meter and glow show): set when you step on a mat; stays while you are within 24 blocks of it
  (§12 Q2), so you can walk to a red gap and fill it; cleared further away, on a new world, or when the home is removed.
- Toasts on change (your own home, you within 32 blocks): finished -> "Your Cozy home is ready! Cozy creatures may
  come to visit." (`type.name`, `sound.play('doorchime')`); unfinished -> "Your home needs fixing. Stand on the
  Doormat to see what is missing."
- **`load` validation:** records must be objects with integer in-bounds `x, y, z`, a string `owner`; unknown `type` ->
  null; drop a record whose block is not a Doormat (edit lost, gym protection, ...); one per owner (the last wins).
  Old saves have none.

## 5. Spawning (T21 seam) and indoor creatures (`creatures.js`)

- `main.js`: `game.creatures.env = { time, friends, homes: () => game.homes.ready() }`. `Home` already has `type`,
  `x/y/z`, `full`, `spawnSpot()`.
- **Underground homes count too** (§12 Q6): in T21's `context()`, `homes: !env?.homes ? [] : ...` (drop `under ||`),
  and `trySpawnCave` gets the same `place` branch as `trySpawn` (move T21's branch into a helper `spawnPlaced(species,
  when, ctx, spawnPoint)` used by both).
- Placed spawns pass `indoor: true` to `spawnAt` (`wild.indoor = true`). Today a creature inside a house would be
  lifted onto the roof (`groundY` uses `world.surface`). Indoor creatures walk like cave creatures:
  `caveGroundY(x, z, fromY, underOnly = true)` skips the `y >= ground - 1` test when `underOnly` is false; `updateOne`
  uses it when `w.cave || w.indoor`. Walls stop them (no floor/air at a wall column). The leave rule becomes
  `wrongTime = !condOk(w.when, ctx) || (!w.indoor && !!w.cave !== under)`.

## 6. UI (`src/homeui.js`: `createHomeUi(game, { atlas, texture })` -> `game.homeUi`)

All of it renders `home.result` / `home.report` and the `HomeType` fields; no type ids in this file.

### 6.1 Meter (HUD, `#home-meter`, shown while `game.homes.active` and no panel/battle)
One row of big icons (48 px, little text): title "Your home" / "Mia's home" + `type.name`;
- room checks: **walls** (brick icon), **roof** (house icon), **size** (ruler icon + "6x7"): a green tick or red cross
  badge; `null` = grey "?";
- the rule (if any): its block icon (`drawBlockIcon(atlas, rule.icon)`) with tick/cross and "have/need";
- the features: their block icons, lit (full colour) when done, dim (`opacity .35`) when not; under each a heart
  (`.heart.on` red / grey) for `show: 'hearts'`, or "have/need" for `'counter'`;
- when `finished`: the row gets a gold border and a "Ready!" tick.
- No type chosen yet: "Choose a home type" + tap target. Classes for tests: `.chk.walls|roof|size` with `.ok`/`.bad`/`.unk`,
  `.feat[data-key]` with `.done`, `.heart.on`, `.count`.
- Placement: top centre (`top: 12px`); touch mode below the `#touch-top` buttons (`top: 70px`). `pointer-events: auto`
  on touch (tap = `game.openHome()`), `stopPropagation` on pointerdown.
- Rebuild the DOM only when the result changes (compare a short key), not every frame.

### 6.2 Red glow and floor outline (in the world)
- One `InstancedMesh` (box 1.02, `MeshBasicMaterial({ color: 0xff3030, transparent, opacity, depthWrite: false })`,
  capacity 64) at `holes.wall`, `holes.roof`, `holes.floor` (nearest to the player first if more than 64); opacity
  pulses 0.25-0.6 (1 Hz) in `update`. Matrices are written only when the report changes.
- `size === 'small'`: a red `LineSegments` rectangle around the inside box at `f + 1.02` (the floor outline).
- Both only while `active`; at most 2 draw calls.

### 6.3 Home panel (`#home`, an `.overlay` like `#blocks`; `ui.panelOpen` includes it, `closePanel` hides it)
`main.js` `togglePanel('home')` opens it like the others (exits pointer lock, hides pause; closing calls
`afterOverlay`). Three views, `game.homeUi.open(view)`:
- **`choose`**: "What kind of home?" and one big card per `HOME_TYPES` entry: a picture (the type's example rendered
  once to a 240x180 data URL with the preview renderer, cached), `type.name`, a type chip (`TYPE_COLORS[type.creature]`),
  `type.blurb`. Tapping a card: `game.homes.choose(home, id)`, close, toast "This is your Cozy home now!".
- **`home`**: the meter big (same renderer as 6.1, plus one-word labels under the icons: "Walls", "Roof", "Size",
  feature `name`s), one hint line built from the first failing check (generic texts: "Close the red gaps in the walls.",
  "Make a door: 1 or 2 wide, 2 high.", "Fill the red holes in the roof.", "Make the room at least 8 by 8.", "Put the
  Doormat inside, by the door.", "Add more: " + missing feature names), buttons **Show me a house**, **Change home
  type** (own home only), **Close**.
- **`preview`**: a canvas (about 420x320, smaller on phones), **Back** and **Close**, and the feature icons in a row
  (missing ones blink in step with the model).

### 6.4 The spinning example model
- `blockMesh(blocks, texture)`: a tiny mesher for a block list using `FACES` (export it from `world.js`) and the block
  tiles; per-face shade as vertex colour (`r = g = b = face.shade`), `MeshBasicMaterial({ map: texture, vertexColors: true,
  alphaTest: 0.5 })`. One mesh per tag group so groups can blink.
- Its own `THREE.WebGLRenderer({ canvas, antialias: true, alpha: true, preserveDrawingBuffer: true })`, made lazily
  once and kept. Rendered from `game.homeUi.update(now)` (called in `frame()`) **only while the preview is open**, at
  most 30 fps.
- Spins at 0.35 rad/s; **drag** (pointer events on the canvas, pointer capture, one pointer) turns yaw and pitch
  (clamped); **pinch** (two pointers: ratio of distances) and **wheel** zoom (0.6x-2x). `touch-action: none` on the
  canvas, `stopPropagation` on its pointer events. Spinning pauses while dragging and resumes 2 s later.
- **Blink:** the missing set = failing room checks (`walls`, `roof`, `floor`) + the rule key if not done + feature keys
  not done (of the player's active home; if the active home has another type, or none, nothing blinks). Groups with a
  missing tag toggle `visible` every 0.4 s.
- `game.homeUi.state()` for tests: `{ view, yaw, pitch, zoom, blinkOn, missing: [...] }`.

### 6.5 Prompts and buttons (`main.js`)
- `updateTarget` prompt fallback: on a mat, `Your home · press H` / `Mia's home · press H` (desktop) and touch
  `setAction('My home')`; touch `interact`: `if (!interact() && game.homes.onMat) game.openHome()`.
- Keys: **H** toggles the home panel while on a mat or while it is open; **E** with nothing targeted on a mat opens it.
  Never open it on a mouse click (a click on the mat breaks blocks as always).
- Old saves without `toldHomes`: one toast "New! Put a Doormat in the floor to build a home. Find it in the Blocks
  panel." and save `toldHomes: true` (like `toldCaveGym`).

## 7. Save and play-together

- **Save:** `snapshot()` adds top-level `playerId` and `toldHomes`, and `homes: game.homes.toSave()` in the world part
  (`home` object). While visiting, `game.homeWorld` must hold your own world's homes: `playtogether.js` `loadWorld`
  adds `homes: game.homes.toSave()` to `game.homeWorld` before swapping. `continueGame`: `game.playerId = ...`,
  `game.homes.load(saved.homes, game.playerId)`; `startNew`: `game.homes.load([], game.playerId)`. `createWorld` calls
  `game.homes.reset(world)`.
- **Multiplayer (`multiplayer.js`):** `EVENTS` += `'home'`; `sendHome(record)` sends `{ id, home }`; `listen` ->
  `this.hooks.home?.(p.home)` for other ids. `sendWorld` adds `homes: g.homes.toSave(), owner: g.homes.worldOwner` to
  **every part** (small); `gotWorld` passes them on; `playtogether` `loadWorld` calls
  `game.homes.load(data.homes, data.owner)` after `createWorld`; hook `home: rec => game.homes.apply(rec)`.
  Records carry the player's `name` (`game.mp.name`, '' when alone).
- Homes and their creatures work for everyone (each browser spawns at `ready()` homes; until T25 each screen has its
  own visitors). The host's save keeps visitors' homes; a visitor's own save keeps only their own world's homes.
- **`WORLD_VERSION` 7 -> 8** (comment "8: T22 home blocks"): an older game would crash on block ids 70-72, so it
  gets "Your friend has a newer game. Please reload the page!" instead.
