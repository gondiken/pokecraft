Owner (ROADMAP, waves 7–8): "too many exceptions". Today the guide (`src/guide.js`) has one `if` per gym kind
(night, sky, cave, tower). T19 adds three more kinds (Clock Tower: open by time of day per floor; Hidden Hill:
the arrow fades out ~20 blocks away; Firewall Maze: plain surface) and T23 two more (Cozy: "home", Treasure:

same toasts in the same order, same sky pad tips, same cave stairway path, same night note. A golden-file spec
(§6) recorded on the old code proves it.

gyms. T17 (bigger map, gym protection) and T18 (new types) are built **at the same time** by other builders: see §7.

Facts the design relies on:
- "Where" comes from the **placed gym object**, not the def: a `place: 'cave'` def that found no room (Fossil on
  seed 122, Goo on seed 22) is a plain surface gym with no `g.cave`. So: `g.sky` → sky, `g.cave` → cave, else surface.
- "When" comes from the def: `def.night` (Comet, Saucer). The Saucer Gym is simply sky + night.
- The tower object has `def = TOWER` (`name: "Champion's Tower"`), no `sky`/`cave`/`night` → surface + always,
  but its welcome text is its own.

## 1. The access object (new file `src/access.js`)

One object per gym (and one for the tower), cached. Interface (every method gets the player's position `p`, a
`THREE.Vector3`; all read live game state, nothing is stored on the gym):

```js
{
  gym, name,                 // the placed gym object, def.name
  where, when,               // kind names, e.g. 'sky', 'night' (for tests / debugging)
  aim(p)        -> { x, z, text(arrow, dist) }   // arrow target + guide text; x undefined = no arrow
  tips          -> null | (p, told) => string[]  // toasts to show near this gym; `told` = scratch object the guide
                                                 // resets when the nearest gym with tips changes
  contains(p)   -> boolean                       // the player is inside (for the welcome toast)
  welcome()     -> string                        // the toast when you walk in while it's open
  wait()        -> null | string                 // non-null = the arrow should skip it for now; the phrase for the note ('at night ☾')
  closedText(npc?) -> null | string              // non-null = closed: what to say (walk-in toast with no npc; talkTo passes the npc)
  isOpen(npc?)  -> boolean                       // !closedText(npc)
}
```

`wait()` and `closedText()` are separate on purpose: a closed gym you **can't do anything about** right now (night
gym by day) is skipped by the arrow; a closed gym where you **have work to do** (T23 keys vault, T19 Clock Tower
floors) is not skipped but its people refuse.

### 1a. Code (builder: copy the texts from guide.js exactly; this is the shape)

```js
// Gym access: where a gym is (surface, cave, sky, ...) and when it is open (always, night, ...), one small
// piece each, combined per gym. The guide only talks to these objects. Add a kind by adding an entry to WHERE
// or WHEN; a gym picks one with def.access = { where, when } (else from how it was placed and def.night).
import { WORLD_W } from './world.js';

// where-pieces: (g, game, deps) => { aim, tips?, contains?, welcome? }
export const WHERE = {
  surface: g => ({
    aim(p) {
      const x = g.x + 0.5, z = g.z + 0.5;
      return { x, z, text: (arrow, dist) => dist < 8 ? `${g.def.name} is here!` : `Next: ${g.def.name} ${arrow} ${dist}m` };
    },
  }),
  sky: g => ({
    aim(p) { /* guide.js 70, 73–78 and 103–105 verbatim: h, onIsland, above, pad target; text uses the dist to
                the final target, exactly as now */ },
    tips(p, told) { /* guide.js 48–57 verbatim, with skyToldNear -> told.near, skyToldPad -> told.pad, sky -> g;
                       push the two toast strings into an array and return it (near first, then pad) */ },
  }),
  cave: (g, game) => ({
    aim(p) { /* guide.js 70, 79–91 and 101–102 verbatim (needs game.world.ground and WORLD_W); 'out' -> target the
                mouth; 'in' -> target the centre, text uses its own distance to the centre as now */ },
  }),
};

// when-pieces: (g, game, deps) => { wait, closedText }
export const WHEN = {
  always: () => ({ wait: () => null, closedText: () => null }),
  night: (g, game, deps) => ({
    wait: () => (game.night ? null : 'at night ☾'),
    closedText: () => (game.night ? null : nightClosed(game, deps, g.def)),
  }),
};
// minutesToNight + nightClosed: guide.js 8–19 verbatim, with game/deps passed in.

export function createAccess(game, deps) {   // deps = { dayLength, smoothstep }
  let cache = new WeakMap();
  function of(g) {
    let a = cache.get(g);
    if (a) return a;
    const spec = g.def.access || {};
    const where = spec.where || (g.sky ? 'sky' : g.cave ? 'cave' : 'surface');
    const when = spec.when || (g.def.night ? 'night' : 'always');
    const w = WHERE[where](g, game, deps), t = WHEN[when](g, game, deps);
    a = {
      gym: g, name: g.def.name, where, when,
      aim: p => w.aim(p),
      tips: w.tips ? (p, told) => w.tips(p, told) : null,
      contains: w.contains || (p => (g.tower ? game.world.towerAt(p.x, p.z) : game.world.gymAt(p.x, p.z, p.y)) === g),
      welcome: w.welcome || (() => (g.tower ? "Welcome to the Champion's Tower!" : `Welcome to the ${g.def.name}! (${g.def.type} type)`)),
      wait: () => t.wait(),
      closedText: npc => t.closedText(npc),
      isOpen: npc => !t.closedText(npc),
    };
    cache.set(g, a);
    return a;
  }
  // forget(): drop the cache (tests that change def.access; a new world needs nothing: new gym objects).
  return { of, forget: () => { cache = new WeakMap(); }, WHERE, WHEN };
}
```

Notes:
- An unknown kind name should throw a clear error (`Unknown gym access 'x' for <gym id>`), not fail silently.
- `contains` default reproduces line 60 exactly: looping the gyms in `world.gyms` order and taking the first `g`
  with `gymAt(...) === g` gives what `gymAt` returns; then the tower via `towerAt`.
- `g.tower`, `g.sky`, `g.cave`, `def.night` checks live **only** in `createAccess` (choosing the pieces) and the
  tower's default welcome. Nothing else in the code base asks about gym kinds for guiding.

## 2. The guide after T16 (`src/guide.js`)

```js
// The guide arrow and the "Welcome to the ..." / "closed" toasts. It knows nothing about kinds of gyms: it asks
// each gym's access object (src/access.js) where to point, what to say and whether it is open.
export function createGuide(game) {
  const acc = g => game.access.of(g);
  let tipGym = null, told = {}, currentGym = null;

  function updateGuide() {
    const p = game.player.pos;
    const unbeaten = game.world.gyms.filter(g => !game.badges.includes(g.def.id));
    let next = unbeaten[0], note = '';
    // Gyms you have to wait for (night gyms by day) are skipped, and the arrow names them.
    if (next && acc(next).wait()) {
      const other = unbeaten.find(g => !acc(g).wait());
      if (other) {
        const groups = new Map(); // phrase -> names, in gym order
        for (const g of unbeaten.slice(0, unbeaten.indexOf(other))) {
          const w = acc(g).wait();
          groups.set(w, [...(groups.get(w) || []), acc(g).name]);
        }
        note = [...groups].map(([w, names]) => ` · ${names.join(' and ')} ${names.length > 1 ? 'open' : 'opens'} ${w}`).join('');
        next = other;
      } else note = ` (opens ${acc(next).wait()})`;
    }
    if (!next && !game.champion && game.world.tower) next = game.world.tower;
    if (!next) game.ui.setGuide('★ Champion! ★');
    else updateArrow(p, next, note);

    // Tips near a gym (today: the sky gyms' "build a tower" and pad tips), for the nearest unbeaten gym that has them.
    const dist = g => Math.hypot(g.x + 0.5 - p.x, g.z + 0.5 - p.z);
    const near = unbeaten.filter(g => acc(g).tips).sort((a, b) => dist(a) - dist(b))[0];
    if (near !== tipGym) { tipGym = near; told = {}; }
    if (tipGym) for (const msg of acc(tipGym).tips(p, told)) game.ui.toast(msg);

    const inside = [...game.world.gyms, game.world.tower].find(g => g && acc(g).contains(p)) || null;
    if (inside !== currentGym) {
      currentGym = inside;
      if (inside) game.ui.toast(acc(inside).closedText() || acc(inside).welcome());
    }
  }

  function updateArrow(p, next, note) {
    const aim = acc(next).aim(p);
    let arrow = '', dist = 0;
    if (aim.x === undefined) game.guideTarget = null;
    else {
      game.guideTarget = [aim.x, aim.z];
      /* guide.js 93–99 verbatim: dx, dz, dist, rel, arrow */
    }
    game.ui.setGuide(aim.text(arrow, dist) + note);
  }

  return { updateGuide };
}
```

  `' · Comet Gym and Saucer Gym open at night ☾'`. With only night gyms left: `' (opens at night ☾)'`.
- Tips: today's set is "unbeaten `g.sky` gyms" in `world.gyms` order, sorted by distance (stable) → same as
  "unbeaten gyms whose access has tips". Today's flags reset to `false` when `skyNearest` changes, also when there
  is no sky gym left (`undefined !== null` on the first call; harmless) → same with `told = {}`. Compare **gym
  objects** (not access objects) for "nearest changed" so `forget()` in tests doesn't reset tips.
- Order of side effects in one call stays: `setGuide`, then tip toasts (near, then pad), then the walk-in toast.
- Tower: surface piece → `"Next: Champion's Tower ↗ 34m"` / `"Champion's Tower is here!"`; walk-in →
  `"Welcome to the Champion's Tower!"` (always open, so `closedText()` is null).
- `game.guideTarget` is still set on every arrow update (now `null` only for "no arrow" kinds, none today).
- The guide no longer imports `WORLD_W` (the cave piece does).
