## 0. Facts measured before planning (node, this container)

- Map 224×224×48 (`WORLD_H` 48), `WATER_LEVEL` 12. Natural height `h = min(terrainHeight, 38)`:
  p10 = 11, median 15–17, p90 19–21, p99 23–26. Rock (stone/ore) is `y <= h-4`, dirt `h-3..h-1`.
  So there are only ~10–14 layers of rock under normal land: caves live in **y = 2 .. h-3**,
  mostly under hills. That's fine; don't try to go deeper (heights can't change, y=0 is the floor).
- `generate()` 60–200 ms, `buildAll()` 330–490 ms, 395k–465k triangles (seeds 1, 4242, 99, 123456, 777).
- A prototype of the worm carver below (40 worms + 8 entrances) carved 6–10k air blocks in
  **< 10 ms**, and added **+6–9 % triangles** and no measurable `buildAll` change.
- Terrain-height checksum for seed 4242 (used by the map spec, section 9):
  `sum over x,z step 3 of terrainHeight(x,z) * ((x*7+z)%13+1)` = **596409**.

**Budget** (builder must check with a node script like the one in section 9 and report numbers):
carving + decoration ≤ 40 ms per world; `buildAll` ≤ 1.3× the no-caves time; triangles ≤ +12 %;
one `buildChunk` of a cave chunk ≤ 8 ms on desktop.

## 1. Where caves may go (hard rules)

All carving happens in `carveCaves(world)` in `src/caves.js`, called from `World.generate()`
**right after the terrain loop and before the plants loop** (so plant positions, which use
`surface()`, stay as they are everywhere except at entrance holes). Gyms/tower are placed later,
unchanged.

1. **Natural heights cache**: in the terrain loop store `this.ground[x + z*W] = h` (new
   `Uint8Array(W*D)` in the constructor). `terrainHeight`, `biome`, `highGround` are not changed.
2. **Solid roof**: a normal cave cell must have `y >= 2` and `y <= ground - 3` (at least 3 solid
   blocks above, so the surface and everything built on it is untouched). Only entrance worms
   (rule 5) may carve above `ground - 3`.
3. **Keep-out mask** `keep = Uint8Array(W*D)` (1 = never carve in this column):
   - map edges: within 4 of any side;
   - water/beach: every column with `ground <= WATER_LEVEL + 2`, dilated by 2 in x/z (so no cave
     cell ever touches the sea or a lake);
   - gyms: Chebyshev distance ≤ 18 from each spot of `this.gymSpots(GYMS.length)` (pure: uses only
     hashes). 18 > the 15-block slope area `buildGym` reshapes;
   - tower: ≤ 18 from `towerSpot()`. `towerSpot` reads `this.gyms[i].x/z`; give it a parameter
     `towerSpot(gyms = this.gyms)` and pass `spots.map(([x, z]) => ({ x, z }))`. Must return the
     same spot `placeTower` later picks (it will: same inputs);
   - spawn: ≤ 12 around the map centre, and ≤ 10 around a spawn guess: the same outward ring search
     as `findSpawn` in main.js (first column whose top block is `B.GRASS`) run on the terrain-only data.
   Optional, owner decision D1: nothing about edits goes into the mask (see 1.6).
4. **Worms** (seeded `mulberry32(seed ^ 0x5eed)`, never `Math.random`): 40 worms. Start at a
   random non-keep-out column with `ground >= WATER_LEVEL + 5`, `y = 3 + r*(ground-8)`. Each walks
   60–140 steps: `dyaw = dyaw*0.8 + (r-0.5)*0.35`, `pitch = pitch*0.85 + (r-0.5)*0.25`, step 1 block,
   carving an ellipsoid ball of radius `1.3 + 0.8*sin(step*0.3 + r)` (vertical axis squashed ×1.4)
   at each step. Clamp centre `y >= 3.5`; if the centre gets above `ground - 5` push it down and
   point pitch down. Stop at the map edge. A ball only removes cells that pass rules 2–3 (per cell,
   using that cell's own column), and never water/air.
5. **Entrances** (6–8 per world): pick columns with `ground >= WATER_LEVEL + 6`, not keep-out,
   and a **hillside**: some neighbour 3 blocks away is ≥ 3 lower. Start a worm at `y = ground`,
   pitch −0.5 trending down (≥ −0.7), allowed to break the surface while `y > ground - 6`, then
   it continues as a normal worm (roof rule back on). Record `entrances.push([x, z])` and every
   column whose top changed in `opened` (a `Set` of column indices).
6. **Edits apply on top**: unchanged code path: `generate()` then `applyEdits()`. A player's
   blocks always win. Old saves: surface builds are untouched (roof rule), except if an entrance
   happens to open next to them (rare). A player's own mine may now break into a cave. See D1.
7. **Underground lakes**: 4–6 "lake rooms": an ellipsoid (rx, rz 4–6, ry 2.5) centred at `y = 3`
   at a random worm step deep under a hill (`ground >= 18`), carved down to `y = 1`. Then one
   global rule: **every carved cell with `y <= 2` becomes `B.WATER`**. Because the rule is global
   there are never water "walls"; lakes are 1–2 deep (safe for kids; the player can swim).

Result on the world: `world.caves = { air, entrances, opened, floors, crystals, chests }`
(`floors` = up to 300 sample `[x, y, z]` of deep cave floor cells: air, solid below, air above,
`ground - y >= 5`; handy for tests, screenshots and spawning). `generate({ caves = true } = {})`
lets tests build the no-cave world for comparison.

## 2. Inside the caves (decoration, in `carveCaves`, after flooding)

Walk the list of carved cells (keep their indices in an array while carving; no full-world scan).
All choices via `hash2`-style hashing of the cell with `seed + 505..` so they're deterministic.

- **Ore on cave walls**: each stone cell touching cave air: hash < 0.012 → `GOLD_ORE`, < 0.06 →
  `COAL_ORE` (the existing in-rock ore stays as is). Gold already drops a cube 35 % of the time.
- **Star crystals** (existing `B.CRYSTAL`, already glowing and placeable): ceiling cells (solid
  above an air cell, `ground - y >= 4`) hash < 0.015 → replace the ceiling block with CRYSTAL;
  floor air cells hash < 0.008 → a crystal 1–2 tall standing on the floor.
- **Glowcap** (new glowing mushroom block, section 3): floor air cells on stone/dirt, hash < 0.02.
- **Treasure chests**: up to 8 per world, in `floors` cells with `ground - y >= 6`, at least 24
  apart, never in water; put a Glowcap on one free neighbour floor cell so it can be spotted.
- Aim: roughly one glowing block per 50–80 cave-air cells; print the ratio in the spec.

## 4. Darkness (lighting)

Today brightness is global: `materials.solid/water.color.setScalar(lit)` in `updateSky`. Keep that
idea for day/night/weather, but bake **where** light reaches into the vertex colours.

**Vertex colour packing** (solid and water meshes; glow mesh unchanged = `shade, shade, shade`):
`r = shade * sky`, `g = shade * block`, `b = shade`, per face (flat; all 4 corners alike). `sky` and
`block` are read at the **air/water cell the face looks into** (`x+dir`, `y+dir`, `z+dir`).

**Sky light** (`World.skyAt(x, y, z)`, also used for "underground"):
```
outside the map in x/z -> 1
c = x + z*W
if (y > this.top[c] || this.litCol[c]) return 1     // open sky above, or inside a gym/tower
d = this.ground[c] - y                               // depth below the natural surface
return d <= 0 ? 1 : Math.max(0.06, 1 - 0.2 * d)
```
- `this.top` (`Uint8Array(W*D)`): highest **occluder** (`isOccluder`) per column, so leaves,
  glass and water don't count: forests, lakes and windows stay bright. Compute it at the start of
  `buildAll()` (runs after `applyEdits`), and keep it up to date in `set()` (placing an occluder
  above `top` raises it; removing the top block rescans down that column).
- "Above the natural ground" is always lit, so houses players build (and their roofs) stay bright;
  only things under cover **and** below the natural surface get dark (caves, basements, mines).
- `this.litCol`: 1 for gym and tower footprints (`R + 2` around each), set at the end of
  `placeGyms`/`placeTower`, because gyms on slopes can have floors below a neighbour's natural height.

**Block light** (lamps, crystals, glowcaps light up what's around them): in `buildChunk`, scan
the chunk plus a 4-block border (24 × 48 × 24) for `BLOCKS[id].glow`; stamp each into a reused
module-level `Float32Array(24*48*24)` (fill(0) per build): `max(old, 0.9 - 0.18 * manhattan)` for
Manhattan ≤ 4. No occlusion (keep it simple). In `World.set()`, when the old or new id glows,
also dirty every chunk overlapping `x±4, z±4`.

**Shader** (in `src/caves.js`, `export const caveLight = { uLit, uLantern, uPlayer }` uniforms and
`export function patchMaterial(mat)` using `onBeforeCompile` + `customProgramCacheKey`), applied in
main.js to `materials.solid` and `materials.water` (not `glow`). With three r160 MeshBasicMaterial:
- vertex: after `#include <project_vertex>` add `vCavePos = (modelMatrix * vec4(transformed, 1.0)).xyz;`
- fragment: replace `#include <color_fragment>` with
  ```glsl
  float lan = uLantern * clamp(1.0 - distance(vCavePos, uPlayer) / 8.0, 0.0, 1.0);
  diffuseColor.rgb *= max(vColor.r * uLit, max(vColor.g, vColor.b * lan));
  ```
  (`sampledDiffuseColor`/map is applied before this include; material `color` stays white.)
- `updateSky`: replace the two `materials.*.color.setScalar(lit)` lines with
  `caveLight.uLit.value = lit;`. So: surface = exactly as before (`shade * lit`); caves are dark at
  any time of day; lamps/crystals/glowcaps light their surroundings independent of day/night (so
  lamps now also light the ground around them at night: D4); thunder flashes barely reach caves.

**The player's light** ("your lead creature glows"): main.js each frame sets `uPlayer` to the eye
position and eases `uLantern` toward `0.75` when underground, `0` otherwise (~1 s fade).
Underground = `world.underground(pos)`: `skyAt(floor x, floor(y + 1.6), floor z) < 0.5`.

**Other things that must dim underground** (main.js `updateSky`, `u` = eased underground 0..1):
`hemi.intensity` and `sun.intensity` × `(1 - 0.6u)` (creatures/NPCs are Lambert-lit and would
glow in the dark otherwise); fog colour lerped toward `#07080c` by `u`, `fog.far` lerped toward 40.
Weather already hides particles when `covered` (15 blocks scan) — nothing to do there.

Optional stretch (only if time, and only if the frame-time check stays green): per-vertex
smoothing (average the 4 cells around each corner) for softer cave edges.

  `trySpawnCave` (up to 4 attempts per 0.6 s tick, since many random spots are rock) instead of
  `trySpawn`. Despawn: add `wrongPlace = !!w.cave !== under` next to `wrongTime` (same "only when
  > 10 away" rule), so the 16-creature cap never fills with creatures from the other layer.
- `trySpawnCave(center, spawnPoint, night)`: random angle, distance 5–18; `y0 = floor(center.y) +
  randInt(-5, 5)`; scan `y0+4 .. y0-6` for a cell that is air, has a solid non-water block below
  and air above, `skyAt < 0.5` and `y < ground - 2`. Species from `pickEntry('cave', night)`;
  `waterOnly` species are never in the table. Level: same formula as `trySpawn` **+ 3**
  (D5; caves are a training spot for late gyms). Set `wild.cave = true`; call `onSpawn`.
- `caveGroundY(x, z, fromY, sp)`: for `y = floor(fromY)+1` down to `floor(fromY)-3`: return `y`
  when `(x, y-1, z)` is solid, `(x, y, z)` is air and `(x, y+1, z)` is not solid, and
  `y < ground - 1` (so they don't wander out of the entrance); else `null`. Also return the ceiling
  (first solid above, max 6) so fliers bob at `min(floor + 1.2, ceiling - 1)`.
- `updateOne`: if `w.cave` use `caveGroundY` (both for the next step and the height target).
  Nothing else in the surface logic changes.

  `'Open chest!'` (the touch action button already calls `interact`).

## 8. Performance (slow renderer, iPad)

- Carving is a one-off < 40 ms. The extra per-face work in `buildChunk` is two array reads; the
  block-light scan is ~28k cells per chunk. Allocate light buffers once (module level), no
  per-face arrays/objects.
- `set()` dirties at most 4 extra chunks, and only for glowing blocks.
- Fog far 40 underground slightly cuts fill rate in caves.
- Report in the commit message: node timings of generate/buildAll/one cave chunk and triangle
  counts before/after for seeds 1, 4242, 99.

## 11. Decisions for the owner (defaults used unless they say otherwise)

- **D1 Old worlds get caves too** (default yes): surface builds are untouched; rarely a new
  entrance opens near a build, or an old mine meets a cave.
- **D2 Chest reward**: 3 Capture Cubes, about 8 chests per world (default).
- **D3 Glowcap is a building block** (default yes); chests can't be placed.
- **D4 Lamps light up the blocks around them** (also at night on the surface) (default yes).
- **D5 Cave creatures are 3 levels higher** than surface ones nearby (default yes; helps the
  late-gym training gap).
- **D6 Player light only underground** ("your lead creature glows"; default yes, no light at night outside).
