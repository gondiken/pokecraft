# T29 · Champion missions (plan)

ROADMAP "Wave 9" T29. After becoming Champion, Champion Solenne gives **missions**, one at a time, with a list of done ones
(per player, saved). Three kinds: **treasure maps** (a map piece with a picture and a clue leads to a dig spot that comes
from the seed), **build challenges** (checks as data, using the home feature helpers) and the **co-op boss** (two players,
play together, two creatures against one giant boss that uses T25 big moves). Rewards: Capture Cubes and three new
**rare mission blocks** (ids 75-77) you can only get from missions.

Runs in wave 9c **after T24/T25/T26/T27/T28 are merged** (it uses T25's `battle.sides`, `cantUse`, `round`, `movesWith`).
**T30 (hide and seek) is built at the same time.** T30 owns its new file(s), its own multiplayer event, `touch.js`, and its own
spec. T29 keeps `main.js`, `ui.js`, `index.html`, `style.css`, `multiplayer.js`, `playtogether.js` edits small and marked
`// T29`, so the merge is "keep both". **T29 adds no multiplayer event** (the co-op boss rides on the existing `duel` event);
**T29 bumps `WORLD_VERSION` to 10** (new block ids) and **duel `VERSION` to 9** (new battle mode). T30 must bump neither.

## 0. Decisions (owner defaults, easy to change later)

| Question | Decision |
| --- | --- |
| Who gives missions | Champion Solenne, only to a player with `game.champion` (and all 27 badges, as today's tower lock already demands). Talking to her opens the **Missions panel** (it also has her rematch button). |
| How many | 12 missions in a fixed order (5 maps, 4 builds, 3 bosses), one active at a time. Appended to, never reordered (ids are saved). |
| Next mission | When one is done you get the reward at once and a toast "Go back to Champion Solenne for your next mission!". The Champion gives the next not-done mission after the last one. |
| Swap | "Do a different one" in the panel (anywhere, not only at the Champion) puts the active mission back and makes the next not-done one active. So a child without a friend is never stuck on a boss mission. |
| Treasure dig | No world change at generation (no checksum, no `WORLD_VERSION` change for that). The spot is a column from the seed; you have found it when you **stand in a hole 2 blocks deep** on the spot (3x3 columns). Same spot for everyone in that world. |
| Map help | Picture (top-down mini map of the real blocks around the spot with a red X), a clue in child words ("With your back to the door of the Splash Gym, walk 14 steps straight ahead, then 5 steps to your left. It is in the forest, near a tree."), and hot/cold words on the HUD chip. |
| Build check | Only **placed** blocks count (`world.edits`), the build connected to blocks near you. Checked by itself every second while the mission is active; "Check my build" button too. |
| Co-op boss | A duel-style shared-seed battle: each browser plays its own creature, the friend's creature is a third model and card, the boss acts every turn by a fixed plan (telegraphed big moves), its target is a shared random draw. Teams are full-HP copies (like duels): nobody's real team is hurt, no XP. |
| Rewards | Map: 4 Star Blocks + 5 cubes. Build: 4 Rainbow Bricks + 5 cubes. Boss: 2 Giant Trophies + 10 cubes for the player with the mission; the helper gets 1 Giant Trophy + 5 cubes (every time; helping a friend is the fun part). |
| Rare blocks | 75 **Star Block**, 76 **Rainbow Brick**, 77 **Giant Trophy**: placeable, `limited` like the treasure blocks, never in the world from the seed. What they are "later used for" stays in the backlog. |
| Not Champion | M / the chip say "Become the Champion to get missions!"; the tower behaves as today. |

### 2.4 `src/treasuremap.js` (spots from the seed, clue words, the picture, the dig check)
```js
// Treasure map spots (T29): 5 columns per world from the seed and the terrain only (world.ground, biome(), the generated gyms,
// tower and new-land slots), never from player edits, so every player in a world gets the same spots. Never change the rules:
// it would move the X in existing worlds. Only the first MAP_GYMS gym defs count as landmarks / keep-outs, so gyms added later
// (T32) do not move them (T32: keep new gyms 12 blocks away from treasureSpots()).
export const MAP_GYMS = 27;
export const MAP_RULES = { edge: 10, gap: 12, pad: 6, slot: 4, spread: 40, start: 14, tries: 400, maxG: WATER_LEVEL + 24 };
export const MAP_LEGS = [ // per map: landmark and how far from its door (steps straight out)
  { from: 'tower', min: 8, max: 16 }, { from: 'gym', min: 10, max: 20 }, { from: 'gym', min: 14, max: 26 },
  { from: 'gym', min: 18, max: 32 }, { from: 'gym', min: 22, max: 40 },
];
export function treasureSpots(world) // cached on the world (world.treasureSpots): [{ k, x, z, g, land: { name, door: [x, z], front }, fwd, side }]
```
Algorithm per map k (in order, so spot k may look at spots < k):
1. `rand = mulberry32((world.seed ^ 0x7ea5a9e) + k * 7919)`.
2. Landmarks: k = 0: `[world.tower]` (name "Champion's Tower"). Else: `world.gyms` whose `GYMS.indexOf(def) < MAP_GYMS`, `def.slot == null`, `!g.home`,
   `!g.sky`, `def.place !== 'cave'`, `g.x != null` (plain surface gyms with a door), in `GYMS` order. Door column = centre + `front * 8` (one step outside).
3. Up to 6 landmark picks `L = list[floor(rand() * list.length)]`; for each up to `tries` candidates: `fwd = min + floor(rand() * (max - min + 1))`,
   `side = round((rand() * 2 - 1) * fwd / 2)`, column = door + `front * fwd` + `left * side` (left as the player sees it with the back to the door:
   **verify the sign in the game**: stand at the door, set yaw to face `front`, compare with `player.forward` x up; write the result in a comment).
4. A column is OK when: inside `[edge, W - 1 - edge]`/`D`; the 3x3 columns around it have `ground > WATER_LEVEL` and `ground <= maxG`;
   Chebyshev distance > `gap` from every `protect` box of every gym (first `MAP_GYMS` defs) and of the tower; > `pad` from every sky gym's `pad`;
   outside every `world.newLandSlots()` box grown by `slot` (all 5 slots, also the spare one); >= `spread` from earlier spots; >= `start` from `(MID_X, MID_Z)`.
5. Nothing found for any landmark: same loop with `gap 8`, `spread 24`, then a plain search over the whole map from the same rand (any OK column,
   landmark = the nearest one of the list, `fwd`/`side` measured from its door; the clue then only says "Look at the map picture!").
Pure function of the seed: two fresh `World(seed)` give the same spots; edits never change them.

```js
// Words for the map (current blocks only add the "near ..." part; the spot itself never moves).
export function clueOf(world, spot) -> { lines: [string], near: string }
```
- Line 1 (way): tower: `Walk out of the door of the Champion's Tower. Go ${fwd} steps straight ahead`; gym: `Stand at the door of the ${name} with your back to it. Walk ${fwd} steps straight ahead`;
  then `side === 0 ? '.' : `, then ${|side|} steps to your ${left|right}.``
- Line 2 (place): biome word from `world.biome(x, z)`: forest "It is in the forest", meadow "It is in a field of flowers", plains "It is on the grass",
  desert "It is in the sandy desert", beach "It is on the beach", swamp "It is in the muddy swamp", taiga "It is in the snowy pine forest",
  mountain "It is on the mountain", snow/peak "It is high up in the snow".
- `near` (current blocks within 4 columns, first match): `FLOWER_BUSH` "near a flower bush", `CACTUS` "next to a cactus", `PINE_LOG` "near a pine tree",
  `LOG` "near a tree", `CRYSTAL` "near a shiny crystal", water within 5 "close to the water", else "on open ground". Joined into line 2.
- Line 3: `Dig 2 blocks down on the X!`
- No numbers bigger than 40, no compass words, no Pokémon terms.

```js
// The map piece: a top-down picture of the blocks around the spot with a red X. size = cells per side (odd).
export function drawMap(canvas, world, spot, colorOf, { size = 41, px = 4 } = {})
```
For each column the colour of its top non-air block (`colorOf(id)`, missionui gives average atlas tile colours), lighter with height
(`1 + (y - spot.g) * 0.04`, clamped 0.7-1.3), water bluish. A red X (2 px lines, 5 cells wide) on the spot cell, a parchment border
and a jagged torn edge (deterministic from the spot). Canvas 164x164 drawn, shown at 240 px with `image-rendering: pixelated`.

```js
// Hot/cold for the HUD and the found check.
export function findCheck(player, spot) -> { dist, word, period, found }
```
`dist` = horizontal distance to the spot centre. Word: > 48 `cold`, > 24 `warm`, > 8 `hot!`, > 1.6 `very hot!`, else `Dig here!`.
`period` = `clamp(0.3 + dist / 12, 0.35, 3)` (pulse). `found` = `|floor(p.x) - x| <= 1 && |floor(p.z) - z| <= 1 && p.pos.y <= spot.g - 0.9 && p.onGround`
(standing in a hole 2 deep: the ground's top block is at `g`). Once the spot is 2 or less away, a one-time toast `You are on the X! Dig 2 blocks down.`.

```js
async coopTurn() {
  const d = this.duel, rank = s => s === 'foe' ? 2 : (s === 'ally') === d.first ? 0 : 1; // the asker (first) is p1
  const mine = this.myOut ? { kind: 'watch' } : await this.chooseAction();
  d.send(mine);
  if (mine.kind === 'giveup') { await this.say('You left the giant battle.'); return 'gaveup'; }
  const theirs = await this.waitForThem(`Waiting for ${d.name}...`);   // the out player sends { kind: 'watch' } every turn
  // me-giveup / left / giveup -> as duelTurn, but giveup says `${d.name} left the giant battle.` and returns 'ended'
  // switches: mine as in duelTurn; theirs -> friendIdx = valid index, await placeFriend()
  const acts = [];
  if (mine.kind === 'move') acts.push(['ally', mine.move]);
  if (theirs.kind === 'move') acts.push(['friend', MOVES[theirs.move] ? theirs.move : 'tackle']);
  if (this.foe.hp > 0) acts.push(['foe', this.bossMove()]);
  acts.sort((a, b) => (MOVES[b[1]].priority || 0) - (MOVES[a[1]].priority || 0)
    || this.speedOf(this.creature(b[0])) - this.speedOf(this.creature(a[0])) || rank(a[0]) - rank(b[0]));   // no draw for ties
  this.clearFlinch();                                         // ally, friend and foe
  const acted = new Set();
  for (const [side, move] of acts) {
    if (this.creature(side).hp <= 0) continue;               // fainted earlier this turn
    if (side === 'foe') this.bossTarget = this.pickTarget(); // draw B, see below
    await this.useMove(side, move, { first: !acted.has(this.other(side)) });
    acted.add(side);
    this.trace.push([this.round, rank(side), move, ...this.hpByRole()]);
    if (this.foe.hp <= 0) return this.coopWon();
    if (this.ally.hp <= 0 && !this.myOut) await this.coopAllyFainted();
    if (this.friend.hp <= 0 && !this.friendOut) { const r = await this.coopFriendFainted(); if (r) return r; }
    if (this.myOut && this.friendOut) { await this.say(`The giant was too strong this time!`); return 'lost'; }
  }
  this.clearFlinch();
  await this.warnBig();                                       // "Giant Cragtusk is getting ready for something big!"
  return null;
}
```

- `coopAllyFainted()`: `faintModel(allyModel)`; say fainted; healthy left -> `pickPartyMember(false)`, `d.send({ kind: 'next', idx })`, `placeAlly()`, `Go, X!`;
  none -> `myOut = true`, `d.send({ kind: 'next', idx: -1 })`, hide the ally model, say `` `Your team is tired out. Cheer for ${d.name}!` ``.

  me-giveup -> `'gaveup'`; left -> `'ended'` (with `leftText`); giveup -> `'ended'`; `idx < 0` -> `friendOut = true`, say `` `${d.name}'s team is tired out!` ``;
