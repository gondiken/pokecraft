## 1. Art direction

**"The Wizard's paint-box sky."** The Swirl is the place between the pictures, where the Wizard's paint never dried.
The colours run in soft pastel streaks across the sky, and each part of the Swirl has its own mood: a bright
candy-sherbet hub where you arrive, a dim violet mist with glowing puffs round the north frames, a warm
peach-and-butter sunset round the south frames, and a deep inky-blue nebula with gold flecks out towards the Wizard.
Moods blend smoothly as you walk (never a hard edge). The odd things floating about are all from a painter's world,
not Wonderland and not space: escaped empty frames that tumble slowly, spinning swirl-wheels, upside-down crayons,
a giant paintbrush dipped in the cloud sea, an inkpot with a quill, an island that "fell up". Decks are pale
"canvas" stone tinted by the mood, lighter on top and deeper underneath, with painted swirls on them, and they shimmer
a little like wet paint. Bright, friendly, a bit silly; the dim parts feel cosy and glowing, never scary.

## 2. Zone layout (160 x 160, coordinates of the T38a tables)

```js
export const ZONES = [ // centre x/z, radius r; weight w = smoothstep(clamp(1 - d / r)); haze adds a constant 0.12; weights are normalised
  { id: 'sherbet', name: '🍧 Sherbet Sky',   x: 50,  z: 80,  r: 26, ... },  // hub (48,80 r11), loopbase, bridgehead, door
  { id: 'mist',    name: '🌙 Moonmilk Mist', x: 48,  z: 42,  r: 30, ... },  // north gallery z 52-57 (w 0.5-0.75), frames N0-N3, Fell-Up Island
  { id: 'sundrop', name: '🌅 Sundrop Shore', x: 48,  z: 116, r: 30, ... },  // south gallery z 103-108 (w 0.7-0.85), frames S0-S2, the paintbrush
  { id: 'inkwell', name: '🖋️ Inkwell Deep',  x: 110, z: 80,  r: 50, ... },  // star bridge x 61-106 fades in, Wizard's island (x 112 for 7 worlds)
];
export const HAZE = { id: 'haze', w: 0.12, ... };
export function zoneWeights(x, z) {}   // -> { sherbet, mist, sundrop, inkwell, haze }, sum 1 (pure; GLSL in 4.2 copies it exactly)
export function zoneAt(x, z) {}        // id of the biggest weight
export function zoneMix(x, z, key) {}  // weighted palette value (THREE-free: [r, g, b] 0..1 from hex) for the sky code
```
Checked by hand: hub centre = sherbet 0.88; spiral stair (48,62) = sherbet/mist/haze mixed (the transition);
north deck = mostly mist; down stair z 91-102 = sherbet -> sundrop; bridge: sherbet at x 61, half inkwell at x 85,
inkwell on the island; map corners = haze only. Neighbouring cells never differ by more than 0.08 in any weight.

## 4. Techniques, files and functions

### 4.1 Sky dome (new `src/swirlsky.js`)
- One `THREE.Mesh(new SphereGeometry(180, 48, 24), MeshBasicMaterial({ vertexColors: true, side: BackSide, fog: false, depthWrite: false }))`,
  `renderOrder = -10`, `frustumCulled = false`, moved to the camera every frame (camera far is 300). 1 draw call, flat
  fragment cost (no sky shader over the full screen: software WebGL hates that).
- **Vertex colours on the CPU every 0.25 s** (or at once when the blended palette moves > 0.01): for a vertex direction
  `d` (h = d.y, az = atan2): sample point `q = cam.xz + norm(d.xz) * 70 * (1 - clamp(h, 0, 1))`, palette `P = zoneMix(q)`,
  `F` = the fog colour at the camera.
  `c = mix(F, P.mid, ss(0.04, 0.3, h)); c = mix(c, P.top, ss(0.3, 0.9, h));`
  bands `b = 0.5 + 0.5 sin(3 az + 10 h² + phase)`, `c = mix(c, P.band, 0.3 ss(0.55,1,b) (1 - ss(0.75,1,h)) ss(0.02,0.12,h))`;
  nebula blobs: `SKY_BLOBS = [[0.8,0.35,10],[2.6,0.2,12],[4.4,0.5,8],[5.6,0.15,14]]` (az, el, power), `c = mix(c, k odd ? P.blobB : P.blobA, 0.55 max(0, d·B_k)^pow)`;
  `h < 0` -> `F`. `phase += dt * 0.03` (bands drift round in ~3.5 min).
  So looking east from the hub you see the inkwell's deep blue rising behind the tower, looking north the mist's
  violet, while the band at the horizon is always the local fog colour (fogged far decks never look like cut-outs).
  Cost: 1 225 vertices x (4 distances + mixes) at 4 Hz, one small buffer upload.

### 4.2 Gradient blocks: a tint in the existing shader patch (`caves.js`)
- `export const swirlTint = { uTintOn: {value:0}, uTintU: {value: Vector4}, uTime: {value:0}, uZone: {value: [Vector4 x4]}, uLo/uHi/uSea: {value: [Color x5]} }`;
  `patchMaterial` assigns it with `caveLight`; `customProgramCacheKey` -> `'cave-light-2'`.
- Vertex shader (after `#include <project_vertex>`), only when `uTintOn > 0.5` and `uv.x` is inside one of the two
  tile ranges `uTintU = (T.SWIRL_STONE_TOP, T.SWIRL_STONE + 1, T.SWIRL_PAINT, T.SWIRL_CLOUD + 1) / TILE_COUNT`
  (the face's tile is in its `u`: no mesh change, no new attribute, player-built blocks and frames stay untinted):
  weights exactly as `zoneWeights` (4-zone loop + haze 0.12), `c = wp.y < 1.5 ? sea : mix(lo, hi, clamp((wp.y - 4) / 26, 0, 1))`,
  `vTint = c * (0.93 + 0.07 sin(wp.x*.23 + wp.z*.17 + wp.y*.3 + uTime*.7))` (the wet-paint shimmer); else `vTint = vec3(1)`.
  Fragment: `diffuseColor.rgb *= vTint;` next to the cave-light line. With `uTintOn = 0` (main world, Dream) the
  output is bit-for-bit today's. Per-vertex, so 146 k vertices, not millions of pixels.
- Baked vertex colours stay as they are (r = shade x sky, g = block light): Glow Puffs light their cells through `g`,
  which is what makes the pools of light in the dim mist.

### 4.3 Light, fog and sky colour by position (`swirlsky.js` + 4 lines in `main.js` `updateSky`)
- `swirlSky.update(dt, now)` (called in `frame()` right after `updateSky`): target weights at the camera, eased
  (`w += (target - w) * min(1, dt * 1.5)`; `snap()` jumps); `swirlSky.fog` (THREE.Color), `near`, `far`, `lit` = weighted.
  Outside the Swirl these are `null`.
- `updateSky`: in the `look.still` branch `scene.background.copy(game.swirlSky?.fog ?? REALM_SKY.setHex(look.sky))`, fog
  near/far from `swirlSky` when set, and `const floor = game.swirlSky?.lit ?? look?.light ?? 0`. Nothing else changes
  (Dream path untouched). Closer fog in the mist also lets `World.cull` drop chunks there.
- Zone-name toast once per trip when a zone's weight passes 0.6 (not for the arrival zone): `🌙 Moonmilk Mist`, etc.
- Cost per frame: one `zoneWeights` call + a few colour lerps.

### 4.4 Nebula puffs and sparkles (`swirlsky.js`, 2 draw calls)
- **Puffs:** one `THREE.Points`, `PointsMaterial({ size: 26, map: soft radial 64x64 canvas, vertexColors, transparent,
  opacity 0.32, depthWrite: false, fog: true })`; `onBeforeCompile` adds `uTime` and a per-point `aPhase` so each puff
  bobs `±1.5` slowly. Positions from `PUFFS` (data, below), max 80.
- **Sparks:** one `THREE.Points`, size 0.55, additive, attribute `aKind` (0 = firefly bob/wander via `sin`, 1 = rising
  paint drop: `y += mod(uTime*0.7 + aPhase*14, 14)`), max 400. No per-frame buffer uploads (all motion in the shader).
- `PUFFS` / `SPARKS` are fields `{ zone, x, z, r, y: [y0, y1], n, colors, kind? }`, scattered by `decorList()` with a
  fixed `mulberry32(0x5d1d)` (the seed changes nothing, like the rest of `swirlland.js`):
  - mist: puffs `(48,30) r12 y10-36 n14` pink/teal/lilac, `(48,62) r18 y3-10 n8` under the decks; sparks: 120 teal/pink fireflies over the north deck (x 28-68, z 50-60, y 27-32).
  - inkwell: puffs `(92,62) r12 y4-30 n10`, `(92,98) r12 y4-30 n10`, `(136,80) r14 y10-40 n10` violet/pink/teal; sparks: 100 gold flecks along the bridge (x 60-110, z 74-86, y 21-30).
  - sundrop: puffs `(48,132) r18 y4-18 n10` butter/rose/peach; sparks: 80 rising drops (coral, gold, white) by the south deck and the paintbrush.
  - sherbet: puffs `(40,80) r30 y34-44 n10` white/pink/sky-blue cotton clouds above the hub; sparks: 60 white glitters.
  Rule (spec): every puff >= 10 blocks from every flood-reachable stand cell above y 4 (no big sprite in your face).

### 4.5 Floating oddities (`swirlsky.js`, 2 draw calls) - not blocks, never solid, never saved
- `FLOATERS` (data in `swirlland.js`, 18 entries): **12 escaped frames** (`InstancedMesh`, a merged 4-box frame
  geometry, instance colours gold `#e8b84a` / mint / pink / sky; sizes 3x4, 4x3, 5x5) that tumble about a tilted axis
  (0.15-0.3 rad/s) and bob ±0.6; **6 swirl wheels** (`InstancedMesh` of `CylinderGeometry(1,1,0.15,24)` with a 64x64
  spiral canvas texture, radius 2-3, spinning 0.6 rad/s, facing the map centre).
  Frames: sherbet `(30,64,30) (64,70,32) (36,98,28)`, mist `(30,40,34) (62,38,30) (70,48,40)`, sundrop `(34,122,22) (64,124,20)`,
  inkwell `(84,66,30) (90,94,34) (126,66,36) (128,96,30)`. Wheels `(20,60,34) (74,40,36) (78,104,26) (40,128,26) (100,62,38) (134,80,34)`.
  Rule (spec): each >= 5 from every reachable stand cell, none inside the door box or a frame's view box (`frame.box` grown by 6 towards its front).
- ~18 matrix updates per frame: nothing.

### 4.6 Blocks in the world (`swirlland.js` `swirlLand`)
- Sea: `SWIRL_CLOUD` instead of `B.CLOUD` (ground stays 0).
- **Deck tops get painted swirls:** `paintAt(deck, x, z)` (exported, pure): round decks = arms of an Archimedean spiral
  (hub 3 arms, wizard island 5: `((θ * arms / 2π + r * 0.18) % 1) < 0.28` -> `SWIRL_PAINT`); box decks (galleries,
  loopbase) = wavy stripes `((x * 0.35 + 1.5 sin(z * 0.6)) % 4) < 1.3`; the rest `SWIRL_STONE`. Stairs (spiral,
  straight, loop): every other step `SWIRL_PAINT` (steps are easier to see). Only the top layer; undersides stay
  `SWIRL_STONE` (they take the deep `lo` colour from the height gradient).
- **Lamps by mood:** hub/loop/south posts keep `B.LAMP`; north gallery posts (5) and the Wizard island's two posts get
  `GLOW_PUFF` / `GLOW_PUFF_MINT` alternating; islet crystals become Glow Puffs (alternating).
- `LANTERNS` (hanging Glow Puffs, data): under the north deck's south edge `(32|40|56|64, 23, 57)` and north edge
  `(36|60, 23, 52)` (not near x 44-46: the spiral join), under the hub rim `(40,16,74) (56,17,86)` (each right under the lowest solid cell there).
- `SCULPTURES` (data, one small builder each; all outside every lift box, keep box, frame box, door box and path):
  - sherbet: two **upside-down crayons** hanging tip-down: `(24, 70)` top y 40, length 12 and `(22, 92)` top 38, length 10;
    3x3 pastel wool body (`WOOL.pixie`, `WOOL.ice`), a `SWIRL_STONE` paper band, a 1-cell tip at the bottom.
  - sherbet: the **paint palette** islet `(16, 80) r 7, y 12` (kidney shape: a circle minus a thumb-hole circle at
    `(19, 84) r 2`), five 2x2 paint blobs of pastel wool on top. Replaces islet `[10, 82, 3, 24]` (removed from `ISLETS`).
    Seen behind the door when you turn round at the arrival.
  - mist: **Fell-Up Island** `(48, 30) r 6`: flat face at the bottom (y 33-35), the pointy taper going **up** to y 41,
    two upside-down trees hanging from the flat face (planks trunk down 3, `WOOL.grass` leaf ball), lanterns under it.
  - sundrop: the **giant paintbrush** dipped in the sea: a 2x2 voxel line from `(104, 1, 134)` up to `(116, 30, 122)`:
    first 5 samples `BRISTLE`, 2 samples `PICTURE_FRAME` (the ferrule), the rest pastel wool handle, a `SWIRL_PAINT` knob;
    sea cells in a ring r 3-5 round `(104, 134)` become `SWIRL_PAINT` (the paint puddle).
  - inkwell: the **inkpot** `(96, 106) r 4`: `GLASS` wall y 1-8, `SWIRL_PAINT` "ink" inside up to y 6 (low = deep blue),
    `WIZARD_STONE` rim at y 8, a pale-wool quill leaning out from `(97, 7, 106)` to `(101, 20, 103)`.
- `world.swirl` gains `zones: ZONES`, `decor: decorList()`, `sculptures` (cell lists, for the spec).
- Nothing in DECKS, DOOR, STAIRS, LIFTS, FRAME_SPOTS, FRAME, BRIDGE, WIZARD changes: every T38a contract holds.

### 4.8 `REALMS.swirl` (realms.js, this entry only) and weather
- `version: 2` (old Swirl edits are dropped by `cleanRealmEdits`; `restore` ignores an old `realmPos` and you arrive at

### 4.9 `swirlsky.js` API
`createSwirlSky(game, { scene, camera })` -> `game.swirlSky`: `reset(world)` (dispose everything; build dome, puffs,
sparks, floaters and set `swirlTint` (`uTintOn = 1`, zone uniforms) only when `world.realm?.look?.zones`, else
`uTintOn = 0`), `update(dt, now)`, `snap()`, getters `fog/near/far/lit` (null outside), `info()` ->
`{ zone, weights, lit, fog: hex, objects: { dome, puffs, sparks, frames, wheels } }`. Every mesh has
`userData.swirlSky = true`. main.js: create it next to `game.portal`, `game.swirlSky.reset(world)` after
`game.portal?.reset(world)` in `createWorld`, `update` after `updateSky`, the `updateSky` lines in 4.3. That's all of main.js.
