Owner (ROADMAP T32): new worldly gyms (wave 11: Food's Kitchen, Swarm's Hive, Parkour's Obstacle Course; Dream lives in
the T31 realm) belong in the main world. Grow the map once more **the T17 way**: everything that exists today stays
block for block the same, a new strip of land, a new list of gym slots (terrain only, never changes once set). **Be
careful about speed**: measure load time, frame rate and draw calls before and after (desktop and emulated iPad) and keep
them about the same; grow only as much as the planned gyms need.
Done when: `big-map` covers the new land and slots, old saves are unchanged, and the before/after numbers are in this plan.

### 1.2 Generation is a chain of sizes
Today: a 224 world is `generateArea`; any other size makes a 224 `World`, adopts it and adds the T17 land. New:
```js
// T32: every size of the map that ever shipped. A World of one of them is generated exactly as that version of the game did
// (the one before it, made in its own World and copied in, plus the land added around it). Never change an existing entry.
const SIZES = [[OLD_W, OLD_D], [T17_W, T17_D], [WORLD_W, WORLD_D]];

generate(opts = {}) {
  if (this.realm) return generateRealm(this);
  const k = SIZES.findIndex(([w, d]) => w === this.W && d === this.D);
  if (k < 0) throw new Error(`No map of size ${this.W} x ${this.D}`);
  if (k === 0) return this.generateArea(opts);       // the old map itself (tests)
  const [iw, id] = SIZES[k - 1];
  const inner = new World(this.seed, null, null, [iw, id]);
  inner.generate(opts);                              // 288: today's code path; 224: generateArea
  this.adoptOld(inner);
  this.guardOld = [iw, id];                          // set() throws for any write inside the inner map
  try {
    this.generateNewLand(iw, id);
    if (opts.slotGyms !== false) this.placeSlotGyms(k === 1 ? [0, T17_SLOTS - 1] : [T17_SLOTS, Infinity]);
    if (opts.treasure !== false) this.placeTreasure([iw, id]);
  } finally { this.guardOld = null; }
  this.gyms.sort((a, b) => GYMS.indexOf(a.def) - GYMS.indexOf(b.def));
}
```
For k = 1 (a 288 × 288 World) this is **exactly today's `generate`** (inner 224, `generateNewLand` with 224, slots 0–4,
treasure outside 224). Changes to the helpers, all behaviour-preserving for the 288 case:
- `adoptOld(old)`: use `old.W`/`old.D` instead of `OLD_W`/`OLD_D` (row copies of `data`, `ground`, `litCol`; the cave
  column remap `i % old.W + floor(i / old.W) * W`, which is the identity for 288 → 288 × 352 but keep it general). The list
  of taken-over keys stays (`caves, gyms, tower, litRooms, newGymBoxes, high, extraSpots, caveSpots, newSpots`); add
  `slots` (cache only). The prototype checked that the 288 × 352 world ends up with the same property list as today's world.
- `generateNewLand(IW = OLD_W, ID = OLD_D)`: the inner size replaces `OLD_W`/`OLD_D` (columns outside it get `fillColumn`;
  plants for `3 .. W-4`/`3 .. D-4` outside it, `wide = !(x < IW + 2 && z < ID + 2)`: no trees in rows 288–289).
- `placeTreasure(skip = null)`: `skip` = `[w, d]` of the inner map, replaces the boolean `newLandOnly`
  (`if (skip && x < skip[0] && z < skip[1]) continue`). `generateArea` keeps calling `placeTreasure()`.
- `set()`: `if (this.guardOld && x < this.guardOld[0] && z < this.guardOld[1]) throw new Error('write into the older map at ...')`.
- **No caves in the strip** (like T17 land; §9 Q5). `highGround()` stays pinned to the 224 area, so biome thresholds are
  unchanged and the strip uses the same ones.

## 2. Four south slots (gymplace.js)

### 2.1 `southSlots()` (cached in `this.south`; terrain only; NEVER change once shipped)
Slot indexes continue T17's: **5, 6, 7, 8** (nearest the start first), so a gym def just says `slot: 5`.
```js
export const SLOT_R = 24, SLOT_GAP = 56;  // T17
export const T17_SLOTS = 5;               // slots 0-4: T17 land; 5-8: the T32 south strip
const SOUTH = { n: 4, gap: 52, x0: 27, x1: 260, z0: 314, z1: 324 }; // centres; boxes x 3..284, z 290..348

// The 4 places in the south strip (T32) where gyms go: slots 5-8. Terrain only (seed and constants). The best total of
// T17's slot score over 4 centres at least `gap` apart in x (exact, so no greedy luck). NEVER change: it would move
// these gyms in every world made since T32.
southSlots() {
  if (this.south) return this.south;
  const h = (x, z) => Math.min(this.terrainHeight(x, z), WORLD_H - 10);
  const dry = (x, z) => [[0, 0], [6, 6], [-6, 6], [6, -6], [-6, -6]].every(([a, b]) => h(x + a, z + b) > WATER_LEVEL);
  const score = (x, z) => { // the same score as newLandSlots
    let n = 0;
    for (let a = -16; a <= 16; a += 8) for (let b = -16; b <= 16; b += 8) { const g = h(x + a, z + b); if (g > WATER_LEVEL && g <= 26) n++; }
    return n + (dry(x, z) ? 5 : 0);
  };
  const { n: N, gap: GAP, x0: X0, x1: X1, z0: Z0, z1: Z1 } = SOUTH;
  const col = [];                       // for every centre x: the best centre z (lowest z on a tie) and its score
  for (let x = X0; x <= X1; x++) {
    let best = null;
    for (let z = Z0; z <= Z1; z++) { const s = score(x, z); if (!best || s > best.s) best = { x, z, s }; }
    col.push(best);
  }
  // best[k][i]: the highest total score of k + 1 slots whose last one is col[i]; from[k][i]: the one before it.
  // Ties keep the first (lowest) index found, so the result depends on the terrain alone.
  const best = [], from = [];
  for (let k = 0; k < N; k++) {
    best.push([]); from.push([]);
    for (let i = 0; i < col.length; i++) {
      if (k === 0) { best[k][i] = col[i].s; from[k][i] = -1; continue; }
      let b = -Infinity, f = -1;
      for (let j = 0; j <= i - GAP; j++) if (best[k - 1][j] > b) { b = best[k - 1][j]; f = j; }
      best[k][i] = b + col[i].s; from[k][i] = f;
    }
  }
  let end = -1, top = -Infinity;
  for (let i = 0; i < col.length; i++) if (best[N - 1][i] > top) { top = best[N - 1][i]; end = i; }
  const picked = [];
  for (let k = N - 1, i = end; k >= 0; i = from[k][i], k--) picked.unshift(col[i]);
  const d = c => Math.hypot(c.x - MID_X, c.z - MID_Z);
  picked.sort((a, b) => d(a) - d(b) || a.x - b.x);  // slot 5 = nearest the start
  return (this.south = picked.map(({ x, z }, i) => ({ k: T17_SLOTS + i, x, z, box: pbox(x, z, SLOT_R, 0, WORLD_H - 1) })));
}

// Every gym slot, index = def.slot: T17's five, then T32's four.
gymSlots() { return [...this.newLandSlots(), ...this.southSlots()]; }
```
Expected (prototype, same code; the builder re-measures with the real code and pins them in `big-map`):
`1: [[139,314],[87,321],[27,314],[195,316]]`, `4242: [[131,314],[79,314],[27,314],[232,318]]`,
`777: [[104,314],[156,314],[208,316],[260,314]]`, `294331207: [[104,315],[52,315],[197,314],[249,314]]`.

Why this shape: the boxes (49 × 49, like T17's, so any T19/T23-style builder fits) lie fully in the strip (z 290..348:
2 rows from the seam, 3 from the far edge; x 3..284), are at least 3 apart (gap 52), never touch T17's boxes (those end at
z ≤ 284) and stay ≥ 13 from every treasure spot. A greedy pick (T17's way) finds only 3 slots of 4 on a 233-wide strip
on many seeds; lanes of fixed width gave only 80 % dry slots; the exact best total gives 96 %.

### 2.3 `placeSlotGyms([first, last])` (gymplace.js)
```js
placeSlotGyms([first, last] = [0, Infinity]) {
  const slots = this.gymSlots();
  for (const def of GYMS) {
    if (def.place === 'home') { if (first === 0) this.gyms.push(this.homeGym(def)); continue; } // T23, once (288 layer)
    if (def.slot == null || def.slot < first || def.slot > last) continue;
    const s = slots[def.slot];
    if (!s) throw new Error(`No gym slot ${def.slot}`);
    const b = SLOT_BUILDERS[def.build];
    const g = b ? b(this, def, s) : this.placeGym(def, s.x, s.z);
    g.slot = s;
    this.gyms.push(g);
  }
}
```
