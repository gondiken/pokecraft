## 0. Facts the design relies on (checked in the code)

- `world.gyms` is read by: the guide (`unbeaten`, `inside`), `npcs.populate`, `gymLive.reset`, `protectedAt`
  (`g.protect?.some`), `gymAt` (`g.x`), and `towerSpot`/spot searches (they run in `generateArea`, **before** any new
  land gym exists). Tests iterate it too (§9.1). A gym object with `x: null`, `protect: []` is harmless to all code
  paths (`NaN` comparisons are false); only tests need a filter.
- `placeSlotGyms` runs inside `generate` with `guardOld = true`; `placeTreasure(true)` runs **after** it and hashes
  per cell (no shared random stream), never inside a `protect` box. So a new building in slot 4 changes nothing
  outside slot 4's box, and treasure inside the box simply follows the new stone.
- `setLive` (T19) changes a block for this player only (never an edit, never saved or sent). `LiveCells.want` is a
  no-op when the cell already has the id, so calling it every update is cheap and survives world reloads.
- `editAllowed` refuses breaking/placing in a `protect` box (player, touch, visitors, saved edits). A 1-cell box
  protects a single chest.
- Clicks: `interact()` already calls `game.gymLive.hit(target.block)` before chests; `tapAt` too. The touch **break**
  button calls `breakBlock` directly (no `gymLive.hit`), §4.4 adds one line.
- Golden guide fixture (`access.mjs` A): stays valid if **no new piece has `tips`** and the new pieces' `contains`
  is false in the replay (replay positions are all inside the old 224 area; the replay game has no homes).
- `game.book.caught` is a `Set` of species ids (kept forever, also after letting a creature go).
- `WORLD_H = 48`.

## 3. Cozy Gym (`src/homegym.js`) — builder B

### 3.1 State (pure, used by access and the live object)
```js
// The home type a gym moves into: the HomeType whose gymMovesIn names it (Cozy: 'cozy'). No gym ids in code.
export const homeTypeFor = gymId => Object.values(HOME_TYPES).find(t => t.gymMovesIn === gymId) || null;
export const caughtOfType = (game, type) => [...game.book.caught].filter(id => SPECIES[id]?.type === type && !SPECIES[id].legendary).length;
export function homeGymState(game, g) {
  const type = homeTypeFor(g.def.id), home = game.homes?.worldOwnerHome() || null;
  const owner = !home ? !game.mp?.active || game.mp.role !== 'guest' : home.owner === game.playerId; // visiting = not the owner
  const ofType = !!home && home.type === type?.id;
  return {
    type, home, owner, ofType,
    ready: ofType && home.finished,                 // cozy right now
    movedIn: !!home?.gyms?.includes(g.def.id),      // sticky on the record until the Doormat is gone
    caught: owner ? caughtOfType(game, type?.creature) : 0, need: g.def.moveIn?.caught ?? 3,
  };
}
```
(Use whatever T22 exposes for "am I visiting"; `game.homes.worldOwner === game.playerId` is the intended test.)

### 3.2 Home records carry the moved-in gyms (small T22 extension, `homes.js`)
- `Home.gyms = []`; `toSave()` adds `gyms` when non-empty; `load`/`apply` copy it (validated: strings naming a `GYMS`
  def with `place: 'home'`); moving the Doormat (`place`) and changing the type (`choose`) **keep** it; removing the
  home (mat broken) drops it with the record.
- `HomeManager.setGyms(home, ids)`: sets, sends the record (`mp.sendHome(home.toSave())`, as `choose` does), fires
  `onChange(home, 'gyms')`, then `game.save()`.
So visitors learn it from the world message and `home` messages with no new message type.

### 3.3 Access (`access.js`)
`WHERE.home` (no arrow when there is nowhere to point; arrow to the Doormat otherwise):
```js
home: (g, game) => ({
  aim(p) {
    const s = homeGymState(game, g), h = s.home, n = g.def.name;
    const at = h && { x: h.x + 0.5, z: h.z + 0.5 };
    if (!s.movedIn) {
      if (!s.owner) return { text: () => `Next: ${n} · it moves into your friend's cozy home` };
      if (!h) return { text: () => `Next: ${n} · build a cozy home! Put a Doormat in the floor.` };
      if (!s.ofType) return { ...at, text: (a, d) => `Next: ${n} · make your home a ${s.type.name} ${a} ${d}m` };
      if (!s.ready) return { ...at, text: (a, d) => `Next: ${n} · make your home cozy ${a} ${d}m` };
      return { ...at, text: (a, d) => `Next: ${n} · catch 3 cozy creatures (${Math.min(s.caught, s.need)}/${s.need}) ${a} ${d}m` };
    }
    const here = this.contains(p);
    return { ...at, text: (a, d) => (here || d < 4 ? `${n} is here!` : `Next: ${n} (at home) ${a} ${d}m`) + (s.ready ? '' : " · it's chilly, fix your home!") };
  },
  contains(p) { // inside the home the gym moved into
    const s = homeGymState(game, g), r = s.home?.report;
    if (!s.movedIn || !r?.inside) return false;
    const x = Math.floor(p.x), z = Math.floor(p.z);
    return Math.abs(p.y - (r.f + 1)) < 3 && r.inside.some(([a, b]) => a === x && b === z);
  },
}),
```
(`contains` must not use `this` if the access wrapper calls it unbound: write it as a local function.)
`WHEN.home`: `wait: () => null` (never skipped, Q1), `closedText: npc => (s.movedIn && !s.ready ? (npc ? `${npc.name}:
` : '') + g.def.chilly : null)`, `status: () => ''`. The walk-in toast is then "Brr..." while chilly, else the welcome.

### 3.4 `HomeLive` (`LIVE.home`, one per home gym)
Every 0.25 s (`update(dt)` accumulates):
1. `s = homeGymState(...)`. **Moving in** (only the world owner's browser decides): `s.owner && s.home && !s.movedIn &&
   s.ready && s.caught >= s.need` → `game.homes.setGyms(s.home, [...s.home.gyms, id])`; if the player is within 32
   blocks: `phase = 'knock'` for 2.5 s: all three people stand on `report.door` cells (or the mat), toast
   `Knock knock! ${leader} is at your door!`, `sound.play('knock')`; then toast `${leader}, ${t1} and ${t2} moved
   into your cozy home! Talk to them to battle.` (also straight away when far away).
2. **Placing people** while `s.movedIn`: `spots = home.standSpots(3)` (furthest from the door first): leader
   `spots[0]`, trainer i `spots[i + 1]` (fewer spots → reuse the last one offset by 0.4), feet at `[x + 0.5, f + 1, z + 0.5]`,
   heading towards the door. Recompute only when a key changes: `home.x,y,z` + the report's inside/size + any
   person's cell turned solid (furniture placed on them). `npcs.placeAt(...)`.
3. **Not moved in** (no home, record gone): `npcs.sendAway` all three.
4. Chilly look (cheap, optional): while `!s.ready`, people's arms shiver (`parts.arms` rotation.z ±0.05 at 12 Hz).
5. When `ready` flips back to true while moved in and the player is near: toast `${leader}: Ahh, cozy again. Thank you!`.
`dispose()`: send everyone away. `of('cozy')` exposes `{ phase, spots }` for tests.

Battles need nothing new: `talkTo` → `closedText(npc)` gives "Brr" while chilly; otherwise the T19 two-trainer flow
(trainers first, then the leader), `onBattleEnd` gives the badge. Visitors battle the host's moved-in gym for their own
badge (Q5).

**Protection: none.** The home is the player's build (they must be able to fix it, and breaking the bed is how it
gets chilly). People are not colliders; a block placed on a person moves them (step 2).

### 4.3 `VaultLive` (`LIVE.vault`)
- State from `game.keys` only (no own state, nothing saved here). `has(k) = game.keys.includes(`${id}:${k}`)`.
- `update(dt)` every 0.25 s: for each key: chest cell → `has ? CHEST_OPEN : KEY_CHEST`; light k → `has ? WOOL.treasure
  : COBBLE`; door cells → `all three ? AIR : VAULT_DOOR`; all via `LiveCells.want` (cheap when unchanged; correct
  after `createWorld` before `continueGame` loads the keys, and after a visitor's world loads). Then the compass (§4.4).
- `hit(block)`: a chest cell of this gym → if not `has`: push the key, `sound.play('keyfound')`, toast `You found a
  golden key! (n/3)`; at 3: `You have all 3 golden keys! The vault door is open.` (+ `doorchime`); dig key also toasts
  `Tip: jump and place a block under you to climb out!`; `game.save()`. If `has`: toast `You already have this key.`
  Return true. A door cell: toast the door's wallText with `(n/3)`, true. Else false.
- `prompt(block, how)`: chest → `Golden key chest · ${how} to open`; door → `Vault door · ${n}/3 golden keys`.
- Opening is **per player**: it is `setLive`, so a friend's chest stays closed for them until they open it.

```js
    closedText: npc => (npc || have() >= g.def.keys.length ? null : g.def.locked), // walk-in toast only
    status: () => (have() < g.def.keys.length ? ` · golden keys ${have()}/${g.def.keys.length}` : ''),
  };
},
```
Where = surface (default). Walking up to the vault says "locked" until you have all three, then the welcome.
