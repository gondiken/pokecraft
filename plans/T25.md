# T25 · Big-decision moves: team effects with a price (plan)

61 new moves (from `plans/T25-table.md`, used exactly as decided) in seven **kinds**: `rally`, `shield`, `risky`, `sacrifice`, `curse`, `field`, `lastword`, one handler each in `battle.js`. Whole-team effects (bench too) live in a per-side **team state**. Every creature of a type learns its type's moves via a `BIG` table appended in `L()`. Wild creatures and trainers never get them from the automatic pick; late gym leaders get them only by name.

**`duel.js` `VERSION` stays 8 (T24 bumped it for the wave; T24 and T25 ship together).**

Wave 9b runs T27 (riding: `player.js`, `main.js`, `multiplayer.js`, `ui.js`, `touch.js`, `style.css`, `index.html`) at the same time. **T25 touches none of those.** Battle UI stays in `battle.js`, tags reuse CSS classes `.up`, `.down`, `.zzz` plus inline colour.

## 0. Contract
**fx status kinds** (`game.fx.status(kind, spot, opts)`): `'rally'` (user, `{ type }`), `'shield'` (user, `{ type }`), `'curse'` (target, `{ type, from: userSpot }`), `'field'` (user, `{ type, from: otherSpot }`), `'sacrifice'` (user, `{ type }`). Reused: `'power'`, `'heal'`, `'up'`, `'down'`, `'recoil'`, `'miss'`, `impact(type, spot, { big: true })`.
**Sounds:** `'kind:rally'`, `'kind:shield'`, `'kind:jackpot'`, `'kind:oops'`, `'kind:gift'`, `'kind:curse'`, `'kind:field'`, `'kind:lastword'`. None of the 61 move ids is a `SOUNDS` key (`useMove` plays `fx:<type>` for them).

## 1. Data: `src/species.js` (A)
### 1a. Entries, appended after the `MOVES` literal (keeps the `fx` spec's `firstMove[type]`)
```js
// T25 big-decision moves: one kind (the mechanic) each, a name per type. Learned at these levels:
export const BIG_LEVEL = { shield: 21, rally: 22, curse: 24, field: 26, risky: 29, sacrifice: 32, lastword: 34 };
export const BIG_KINDS = Object.keys(BIG_LEVEL);
const BIG_FX = {
  rally: { atk: 1, def: -2 },          // whole team +1 attack (bench too) until the battle ends; user -2 defence
  shield: { turns: 3, cut: 0.3 },      // whole team takes 30% less for 3 turns; user rests its next move
  risky: { odds: 0.5, times: 3 },      // 50%: x3, else the user hits itself with power 60
  sacrifice: { atk: 1 },               // user faints; the next one in gets full HP and +1 attack
  curse: { odds: 0.4, spd: -1 },       // 40%: foe team -1 speed (bench too)
  field: { turns: 5, boost: 1.5 },     // one type x1.5 for 5 turns, both sides
  lastword: { below: 0.25 },           // only usable below 1/4 HP
};
// [id, name, kind, book text] per type: copied from plans/T25-table.md (61 rows, in table order)
const BIG_MOVES = { normal: [['goteamgo', 'Go Team Go!', 'rally', 'Whole team hits harder. You get softer.'], ...], ... };
for (const [type, list] of Object.entries(BIG_MOVES)) for (const [id, name, kind, book] of list) {
  const power = kind === 'risky' ? 60 : kind === 'lastword' ? 140 : 0;
  MOVES[id] = mv(name, type, power, 1, { fx: { kind, ...BIG_FX[kind] }, sure: kind !== 'risky', big: true, book });
}
const BIG = Object.fromEntries(Object.entries(BIG_MOVES).map(([t, list]) => [t, list.map(([id, , kind]) => [BIG_LEVEL[kind], id])]));
export const isBig = id => !!MOVES[id]?.big;
```
(Adapt to the real `mv` helper signature.) Use `odds`, never `chance` (`chance` = draw 5). No `sig` (the `fx` spec wants 16 signatures). Counts: 61; rally 8, shield 10, risky 8, sacrifice 8, curse 9, field 11, lastword 7.

## 2. Battle rules: `src/battle.js` (A)
### 2a. State
```js
const newSide = () => ({ atk: 0, spd: 0, shield: null, gift: false }); // shield: { until, name } | null
resetSides() { this.sides = { ally: newSide(), foe: newSide() }; this.field = null; this.round = 0; }
```
Called in the constructor and in `start()` next to `this.modMap = new Map()`. `this.field = { type, name, boost, until } | null`.
- `sideOf(c)`: `'ally'` / `'foe'` / null (handle `allies`/`foes` undefined).
- **`mods(c)` seeds a new entry from its team:** `{ atk: s?.atk || 0, def: 0, spd: s?.spd || 0, sleep: 0, justWoke: false, flinch: false, healed: 0, rest: false }`. `placeAlly`/`sendOutFoe` already delete the entry on switch-in, so bench creatures pick up rally/curse on arrival. The active creature gets the step directly when the effect lands.
- `bench(side)` (healthy others), `teamName(side)` (`'Your team'`, `` `${trainer.name}'s team` ``, the duel opponent's, or the wild label), `shieldOn(side)` (`s.shield && s.shield.until >= this.round`), `fieldFactor(type)`, `turnsLeft(until, n)` = `Math.min(n, until - this.round + 1)`.
- `takenFactor(c)`: `(sleep ? 1.25 : 1) * (shieldOn(sideOf(c)) ? 0.7 : 1)`.
**Rounds:** top of `turn()`, before the duel dispatch: `this.round++; await this.tickEffects();` (no draws: expired shields -> `` `${name} wore off.` ``, expired field -> `` `${name} is over.` ``, refresh). Set in round R: `until = R + turns`.

### 2b. `cantUse(side, id)` (buttons, AI, useMove)
```js
cantUse(side, id) {
  const c = side === 'ally' ? this.ally : this.foe, fx = MOVES[id]?.fx;
  if (fx?.kind === 'lastword' && c.hp >= statsFor(c).maxHp * fx.below) return 'only below 1/4 HP';
  if (fx?.kind === 'sacrifice' && !this.bench(side)) return 'no friend can come in';
  return '';
}
```

### 2c. `useMove` order
1. flinch (existing; also `ma.rest = false`) -> sleep (existing; also `ma.rest = false`).
2. rest: `if (ma.rest) { ma.rest = false; refresh; say `${who} is resting after the shield.`; return; }` (no draws).
3. blocked: `why = cantUse(side, moveId)` -> say `` `${who} can't use ${mv.name} now: ${why}!` ``, return (no draws).
4. `ma.justWoke = false`, then as today: draw 1 hit, status moves -> `applyFx`.
5. Damage: draw 2 multi, draw 3 crit, draw 4 roll, then
```js
let mult = 1;
if (mfx?.kind === 'risky') {                 // draw 7: right after the damage roll
  if (this.rng() < mfx.odds) mult = mfx.times;
  else { await this.backfire(side, mv, roll); return; }
}
if (mfx?.kind === 'lastword') { fx?.status('power', this.spot(side)); sound.play('kind:lastword'); }
const dmgNow = () => Math.max(1, Math.floor(base * stab * eff * crit * mult * this.fieldFactor(mv.type) * this.takenFactor(def) * roll));
```
Impact `big: !!mv.sig || mult > 1 || lastword`. After effectiveness: `if (mult > 1 && eff > 0) { sound.play('kind:jackpot'); say('Wow! Three times the power!', 1000); }`. Boss hang-on, multi wake-up, recoil unchanged.
6. `backfire(side, mv, roll)`: power-60 self hit, `selfBase = floor(((2L/5 + 2) * mv.power * atk * stage(ma.atk) * (boost || 1) / (def * stage(ma.def))) / 50) + 2`, `loss = max(1, floor(selfBase * roll * takenFactor(atk)))`, no STAB/type/crit/field; can knock the user out (normal faint flow follows). Sound `kind:oops`, fx `recoil` + `impact(type, own spot)`, flash, say `` `Oh no! ${who} hit itself!` ``.
Draw-order comment: hit (1), hits (2, multi), crit (3), roll (4), risky coin (7, right after 4), effect chance (5), sleep length (6), curse roll (8, first thing in the curse branch). Blocked/rest/sleep/flinch draw nothing. Per move: rally/shield/field/sacrifice 1, curse 2, risky 4, lastword 3 (0 blocked).

### 2d. `applyFx` branches (only curse draws)
- **rally:** `s = sides[userSide]`, `m = mods(user)`; both at +3 -> "can't go any higher", no price. Else `m.atk = min(3, +1)`, `s.atk = min(3, +1)`, sound `kind:rally`, fx `rally`, say `` `${teamName(userSide)} feels stronger! Attack up!` ``; price `m.def = max(-3, m.def - 2)` (if changed: fx `down` `{ stat: 'def' }`, sound `statdown`, `` `${uWho}'s defence went down 2!` ``).
- **shield:** `sides[userSide].shield = { until: round + turns, name }`; `mods(user).rest = true`; sound/fx; `` `${mv.name} covers ${teamName(userSide)} for 3 turns!` `` then `` `${uWho} will rest next turn.` ``.
- **sacrifice:** guard no bench (`But no friend can come in!`); fx `sacrifice`; `user.hp = 0`; `sides[userSide].gift = true`; say `` `${uWho} gave everything for the team!` ``; the turn loop runs the normal faint flow.
- **curse:** `r = this.rng()` (draw 8, always); `r >= odds` -> fx `miss`, `But it didn't work...`; else target side + `mods(target)` spd -1 (min -3; both at -3 -> "can't get any slower"), sound/fx, `` `${teamName(targetSide)} got slower!` ``.
- **field:** `this.field = { type: mv.type, name, boost, until: round + turns }` (replaces); sound/fx; `` `${mv.name}! ${Type} moves are stronger for 5 turns. For everyone!` ``.

### 2e. Gift on arrival
```js
async giftArrives(side) {
  const s = this.sides[side]; if (!s.gift) return;
  s.gift = false;
  const c = side === 'ally' ? this.ally : this.foe;
  c.hp = statsFor(c).maxHp;
  const m = this.mods(c); m.atk = Math.min(3, m.atk + 1);
  sound.play('kind:gift'); this.game.fx?.status('heal', this.spot(side)); this.game.fx?.status('power', this.spot(side));
  this.refresh();
  await this.say(`${this.labelOf(side)} comes in fresh and strong! Full HP and more attack!`, 1400);
}
```
Called at the end of `sendOutFoe()` and in `allyFainted()` right after `Go, X!` (use the real names). No draws.

### 2f. Buttons (`chooseAction`)
Per move `why = mods(ally).rest ? 'resting this turn' : cantUse('ally', id)`; `disabled: !!why`, sub `` `${mv.type} · ${why || moveInfo(id).text}` ``. If resting or all disabled: a wide primary `Rest`/`Wait` button (`value: { kind: 'move', move: ally.moves[0] }`, goes through the rest/blocked path; duels need no change). Switch/Cube/Run unchanged.

### 2g. Tags (`tagsFor`)
`m.rest` -> `<span class="zzz">Resting</span>`; shield on c's side -> `<span class="up">${name} ${turnsLeft}</span>`; field (both cards) -> `<span style="color:${TYPE_COLORS[type]}">${name} ${turnsLeft}</span>`.

### 2h. AI (`pickFoeMove`)
`list = foe.moves.filter(id => !cantUse('foe', id))` (fallback `foe.moves`) for both the best and the random pick. Damage scores × `fieldFactor`; risky 0 if `foe.hp < 0.4 max`. Status: rally `ft.atk < 1 && hp > 0.6 max && fb >= 1 ? 40 + 10 * min(fb, 2) : 0`; shield `!shieldOn('foe') && hp > 0.5 max && fb >= 1 ? 40 : 0`; curse `am.spd > -2 && at.spd > -2 ? 30 : 0`; field `field not already this type && foe has a damaging move of that type ? 45 : 0`; sacrifice `fb >= 1 && hp < 0.3 max ? 50 : 0`.

### 2i. Situations
Wild creatures never know them; team state resets in `start`. Catching unchanged. Bosses have no big moves. Duels symmetric (sides keyed per browser, field/round global, draws only from shared state). Foe sacrifice gives XP like any faint.
