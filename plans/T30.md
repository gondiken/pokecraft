# T30 · Hide and seek (plan)

ROADMAP "Wave 9" T30. A play-together game for two players: one hides (60-second head start while the seeker's
screen is dark and the seeker can't move), then the seeker looks for them with a hot/cold compass. Found = tap / click
the hider, or bump into them. Rounds swap roles; a small score is shown to both. Camo creatures near the hider confuse
the compass.

Built in wave 9c **beside T29** (Champion missions, its co-op boss also uses play together) and right after/beside
**T27** (riding). So: **all logic in a new `src/hideseek.js`**; every edit elsewhere is small and marked `// T30`.
Expect "keep both" conflicts in `multiplayer.js` (`EVENTS`, `listen`), `playtogether.js` hooks, `main.js`, `index.html`,
`style.css`, `CLAUDE.md`, `README.md`. Do not touch `duel.js` `VERSION`, `battle.js`, `riding.js`, `world.js`.

## 1. Decisions (owner may want to revisit)

| Topic | Decision |
| --- | --- |
| Players | **Exactly two**: the inviter and the invitee. Other players in the world see nothing special and get "busy" if they invite either of them (duels too). |
| Starting | Pause screen, Play-together box: one button per other player within **24 blocks**: "Hide and seek with Kid". Further away: a line "Walk closer to Kid to play hide and seek." (works on touch through the II button). Looking at a player still means "ask for a battle". |
| Who hides first | The **invitee** hides first (usually the kid answering "Let's play!"). Then roles swap every round. |
| Authority | The **inviter is the leader**: runs the clock, phase changes and the score, and sends a `round` message at every change and every 2 s (heartbeat). The **seeker** decides "found" (tap/click/bump) and sends `found`; the leader turns it into the point. |
| Timers | Messages carry **time left in ms**, never clock times (two devices' clocks differ). Each side sets `endsAt = performance.now() + left`; a heartbeat only moves `endsAt` if it is more than 1.5 s off. |
| Times | Head start (hide) **60 s**, seek **180 s** (not found = the hider gets the point), break between rounds **6 s**, invite answer 30 s. All in `HS` so the spec can shorten them. |
| Score | Seeker finds the hider: seeker +1. Time runs out: hider +1. Not saved; the game runs until someone stops it or leaves. |
| Play area | A circle of **radius 40** (horizontal) round the middle point of both players when the game starts. Leaving it is blocked like an invisible fence (the move is undone) with a toast at most every 3 s. |
| Gyms | **No hiding in gyms** (and the tower): their `protect` boxes are fenced the same way during a round. Gym doors/lasers are per player (Firewall Maze, Clock Tower, vault), so the seeker might not be able to follow. Invite / accept refuses while you stand inside one. |
| Battles | **No battles during a game** (also the breaks): `startBattle` refuses with a toast; a Camo bump does nothing. Duel invites get "busy". Invites need both players out of battles. |
| Riding | **Gets you off** when the game starts and at every phase change, and no riding during the game (the update loop gets you off again with a toast). Flying would make sky hiding trivial and makes the fence/gym rules messy. |
| Seeker | Dark screen (opaque) with a big countdown; can't walk, break, place or interact (`playing()` is false). Can still press Stop. |
| What the seeker sees | During the seek phase the hider's **name tag and lead creature are hidden** on the seeker's screen (the tag shows through walls). The person is shown normally. |
| Compass | Like the key compass: an icon that glints faster when closer (`period = clamp(0.3 + d / 16, 0.35, 3)`, d = 3D distance to the hider's avatar) plus a word: Cold (d > 30) / Warm (> 15) / Hot! (> 6) / Very hot! No direction. |
| Camo decoys | While a **disguised Camo creature is within 6 blocks of the hider** (hider's own list), the hider sends `help: on`; the hider gets "A Camo creature is helping you hide!" and the seeker's compass wobbles (random period 0.5-3 s each second, word "???") with "A Camo creature is fooling your compass!". Edge-triggered, also carried in every `round` heartbeat the leader sends (the leader knows it if it is the hider; when the leader is the seeker it just uses the last `help`). |
| Leaving | Partner leaves / loses connection (`mp.hooks.left`) or anyone presses Stop -> game over for both, toast with the final score. The non-leader also ends it when no `round` arrives for 10 s ("Lost touch with Dad."). Leaving play together (`mp.close`) resets. |
| Nothing saved | No save fields, no world changes. Block edits made while hiding are normal edits. |

## 2. New `src/hideseek.js`

```js
// Hide and seek (T30): a play-together game for two. The inviter (leader) runs the clock and the score and sends
// `round` messages; the seeker says when the hider is found. Nothing is saved; nothing in the world changes.
import { sound } from './sound.js';
import { el } from './util.js';

export const HS = { hide: 60, seek: 180, brk: 6, answer: 30, radius: 40, near: 24, help: 6, beat: 2, lost: 10,
  bump: 1.0, fenceToast: 3, VERSION: 1 };
const ORDER = { hide: 0, seek: 1, brk: 2 };
export const seekPeriod = d => Math.min(3, Math.max(0.35, 0.3 + d / 16));
export const seekWord = d => (d > 30 ? 'Cold' : d > 15 ? 'Warm' : d > 6 ? 'Hot!' : 'Very hot!');
export function createHideSeek(game, { startBattleBlocked } = {}) -> game.hideSeek
```

State (one object, `null` when no game): `{ id, leader: bool, partner (mp id), partnerName, center: [x, z], n, hider
(mp id), phase: 'hide'|'seek'|'brk', endsAt, score: { [mpId]: n }, help, heardAt, foundSent, result }`.
Plus `asking` (`{ id, to, name, timer }`) and `incoming` (`{ id, from, name, timer, onYes }`) like `Duels`.

API (all methods on the returned object):
- `active` (getter): a game is on. `role`: `'hider'|'seeker'|null`. `frozen`: `active && phase === 'hide' && role === 'seeker'`.
- `nearby()`: other players within `HS.near` (for the menu). `menuButtons()`: elements for the Play-together box
  (see §5).
- `invite(avatar)`: refuse with a toast when `asking` ("Still waiting for Kid to answer."), when busy (in battle, `active`,
  `game.duels.asking/incoming/current`) or when you stand in a gym ("Walk out of the gym first, then ask."); else
  `id = random`, send `{ type: 'ask', v: HS.VERSION, id }`, toast "You asked Kid to play hide and seek. Waiting...",
  timer `HS.answer` -> send `cancel`, toast "Kid didn't answer. Try again later!".
- `onMessage(p)` (from `mp.hooks.hs`, only `p.to === mp.id`):
  - `ask`: `v` mismatch -> `no` + `old`. Busy (`!game.started || game.inBattle || this.active || this.asking || this.incoming
    || game.ui.asking || game.duels.incoming || game.duels.asking || game.duels.current || inGym()`) -> `no` + `busy`.
    Else `game.ui.ask({ text: '${name} wants to play hide and seek! You hide first.', yes: "Let's play!", no: 'Not now',
    hint: 'press Y / N', onYes: accept, onNo: decline })`, `sound.play('ask')`, timer `HS.answer` -> decline.
  - `cancel` (incoming id) -> close the ask (only if `game.ui.asked?.onYes === incoming.onYes`).
  - `no` (asking id) -> toast "Kid is busy right now. Try again soon!" / "Kid doesn't want to play right now." /
    `old`: "Kid needs to reload the game to play (it was updated)."
  - `yes` (asking id): `v` mismatch -> like `old`; still busy (in battle) or partner gone -> send `stop`. Else **start as
    leader**: `center` = middle of my position and the avatar's, `n = 1`, `hider = partner`, `score = { me: 0, partner: 0 }`,
    enter phase `hide` and `sendRound()`.
  - `round` (game id, non-leader): first one starts the game on this side (`leader: false`, takes `center`, `score`).
    Ignore if `(n, ORDER[phase])` is older than ours; newer -> `enter(phase)`; same -> fix `endsAt` if > 1.5 s off.
    Always `heardAt = now`, take `score`, `help` (only when I am the seeker and the leader is the hider), `result`.
  - `found` (leader only, `p.n === n && phase === 'seek' && p.from === seeker`) -> `point(seeker, 'found')`.
  - `help` (seeker side) -> set `help`, toast once per change to on.
  - `stop` -> `end(p.why === 'left' ? ... : '${name} stopped the game.')`.
- `accept()` (invitee): busy re-check -> `no busy`; else send `yes` with `v`. Wait for the first `round` (it starts the game
  here). If none in 10 s: toast "Couldn't start the game. Try again!".
- `decline()`: send `no`.
- `enter(phase)` (both sides, local effects only):
  - Always: `game.riding?.creature && game.riding.stop('quiet')`; `game.player.keys = {}`; `game.touch.reset()`;
    `foundSent = false`; update avatar flags (§4).
  - `hide`: hider toast "Hide! ${partnerName} is counting to 60. Stay inside the play area."; seeker: dark overlay on,
    toast "Close your eyes! ${partnerName} is hiding.".
  - `seek`: overlay off; seeker toasts "Ready or not, here I come!" and "Find ${partnerName}! Tap or click them when you
    see them."; hider toast "${partnerName} is looking for you! Keep still...". `sound.play('ticktock')`.
  - `brk`: toast the result (same words on both sides from `result`): found -> "${seekerName} found ${hiderName}!",
    time -> "${hiderName} hid so well! Nobody found them."; then "Score: Dad 2 · Kid 1. Next: Kid hides!"; found ->
    `sound.play('keyfound')`.
- `sendRound()` (leader): `{ type: 'round', id, n, hider, phase, left: endsAt - now, score, center, help, result }` to the
  partner. Called on every phase change and every `HS.beat` s from `tick()`.
- `tick()` (a `setInterval` of 500 ms, also runs in a hidden tab; returns at once when no game):
  - leader: phase over -> `hide` -> `seek` (`endsAt = now + HS.seek * 1000`); `seek` -> `point(hider, 'time')`; `brk` ->
    `n + 1`, swap `hider`, `hide`. Each change -> `enter` + `sendRound`. Heartbeat every `HS.beat` s.
  - non-leader: `now - heardAt > HS.lost * 1000` -> `end('Lost touch with ${partnerName}. Hide and seek is over.')`.
  - seeker with `foundSent` in `seek` -> resend `found` (lost messages).
  - incoming ask replaced by another `ui.ask` (rematch): `game.ui.asked?.onYes !== incoming.onYes` -> decline.
- `point(who, kind)` (leader): `score[who]++`, `result = { kind, seeker, hider }`, phase `brk`, `endsAt = now + brk`.
- `tag(avatar)` -> bool (used by `interact`/`tapAt`): returns false when no game or the avatar isn't the partner; else
  true always (no duel challenge during a game), and if I am the seeker in `seek` -> `found('tap')`.
- `found(how)`: `foundSent = true`; leader -> `point(me, 'found')`; else send `{ type: 'found', id, n, how }`.
- `update(dt)` (every frame from `main.js`, cheap; nothing when no game):
  - riding during a game -> `stop('quiet')` + toast "No riding in hide and seek. Run and hide!" (max every 3 s).
  - HUD (§3) text every 0.25 s; dark-overlay countdown; last 5 s of the head start -> one `ticktock`.
  - seeker in `seek`: partner avatar -> compass (§3); bump: horizontal distance `< HS.bump` and `|dy| < 1.8` -> `found('bump')`
    (once).
  - hider (both phases): `near = game.creatures.list.some(w => w.disguise && w.pos.distanceTo(p.pos) <= HS.help)`;
    on change send `help` (and set own `help` if leader); on -> toast "A Camo creature is helping you hide!".
- `fence(pos, before, vel)` (called by `main.js` right after `p.update`; does nothing without a game, works in all
  three phases): if `pos` is outside the circle (and `before` was inside) or the feet/head cell is inside any gym/tower `protect` box
  (and `before` was not) -> `pos.copy(before)`, `vel.x = vel.z = 0`, toast "That's the edge of the play area!" /
  "No hiding in gyms!" (max every `HS.fenceToast` s). `before` was a valid spot, so copying it back never puts the
  player in a wall. Gym boxes: `world.gyms` (skip `x == null`) + `world.tower`, each `protect` box.
- `blocksBattle(opts)` -> bool: `active && !opts.duel` -> toast "No battles during hide and seek! Press Stop in the
  pause menu first." (max every 3 s), true.
- `prompt(avatar, how)` / `action(avatar)` for `updateTarget`: partner while seeking -> `"${name} · ${how} to find them!"`
  / `'Found you!'`; partner otherwise -> `"Hide and seek with ${name}"` / `''`; non-partner -> `null` (normal battle prompt).
- `stop()` (Stop buttons): send `stop`, `end('You stopped the game. ...score')`.
- `left(id)`: partner -> `end('${name} left, so hide and seek is over.')`; `asking.to`/`incoming.from` -> clear like duels.
- `end(text)`: toast `text` + "Final score: Dad 2 · Kid 1"; clear timers, overlay, compass, HUD, avatar flags, `state = null`.
- `reset()`: everything off, no toasts (title screen, `mp.close`).
- `state()` for tests: `{ active, leader, role, phase, n, score, left: seconds, center, frozen, help, dark,
  compass: { shown, period, word } }`.

Names in texts: mine = `game.mp.name`, partner = avatar name (keep it in `partnerName`). Score line orders the leader first.

## 10. Messages (event `hs`, all `{ type, id, from, to, name }` + fields)

| type | from -> to | fields | meaning |
| --- | --- | --- | --- |
| `ask` | inviter -> invitee | `v` | "Play hide and seek?" |
| `cancel` | inviter -> invitee | | no answer in time: close the box |
| `no` | invitee -> inviter | `busy?`, `old?` | said no / busy / other version |
| `yes` | invitee -> inviter | `v` | accepted (game starts with the leader's first `round`) |
| `round` | leader -> partner | `n, hider, phase, left (ms), score, center, help, result` | every phase change + every 2 s |
| `found` | seeker -> leader | `n, how ('tap'/'bump')` | resent every 0.5 s until the phase changes |
| `help` | hider -> seeker | `on` | a Camo creature is near the hider |
| `stop` | either | `why` | game over for both |
