# T28 · Gym rematches that get harder (plan)

ROADMAP "Wave 9" T28. After you have a gym's badge, its leader offers a **rematch**. Each win makes the next harder (a few levels more, a fuller team, later moves; T25 big moves come later via a hook), per player, with a prize (cubes, XP), saved as a win count per gym. **The first badge battle does not change.** The Doodle Wizard (+5 per win) will reuse the count, so keep it general.

Wave 9a runs beside **T24** (battle.js rules, duel `VERSION`) and **T26** (traits; `continueGame`, `onBattleEnd`, `makeCreature`). T28 changes **one line** of `battle.js`, not `duel.js`, not `species.js`. Expect small "keep both" conflicts in `main.js`/`CLAUDE.md`.

- `talkTo` (main.js ~682): a leader whose badge you hold starts `gym.leaderTeam` again ("Back for a rematch?..."), win -> "You are as strong as ever!", no cubes, no count. T28 replaces both.

## 2. New `src/rematch.js`
```js
import { GYMS, trainersOf, REMATCH_CAP } from './gyms.js';
import { SPECIES } from './species.js';
export const REMATCH = { step: 3, cap: REMATCH_CAP, maxTeam: 6, xpBoost: 1.5, maxWins: 999, askTime: 20, askRange: 8 };
export const WIN_IDS = new Set(GYMS.map(g => g.id));
export function loadWins(saved) // { [id]: int > 0 } for known ids; drops unknown/non-integer/<=0; clamp 999; arrays/null -> {}
export function grownUp(species, level) // follows `evolve` while level >= evolve.level (max 3 steps, guard missing `into`)
export function rematchMoves(def, tier, species, level, baseMoves) { return baseMoves; } // T25 hook
export function rematchTeam(def, wins = 0, rules = {}) // -> [[species, level, moves?], ...], pure
export const rematchCubes = n => Math.min(8, 3 + n);
```
`rematchTeam` (`R = { ...REMATCH, ...rules }`, `tier = wins + 1`):
1. Base: each `[s, L, moves]` of `def.leaderTeam` -> level `min(R.cap, L + R.step * tier)`, species `grownUp(s, level)`, moves `rematchMoves(...)`.
2. Extras: `extra = min(R.maxTeam - base.length, floor(tier / 2))`. Pool in fixed order: species of `trainersOf(def)` teams not in the leader team (each once), then every `SPECIES` id with `type === def.type`, not legendary, not used. Extra level `min(R.cap, minBaseLevel + R.step * tier - 1)`, grown up, moves from the hook. Extras go **before** the base (signature creature stays last).
3. Drop the third element when moves is undefined.

Properties: levels ≥ badge levels, ≤ cap, never lower with more wins; size never shrinks, ≤ 6; species exist; wins 0 = base + 3.

**Controller `createRematch(game, { startBattle })` -> `game.rematch`:**
- `winsOf(id)`.
- `offer(npc)`: if the box is open for this npc, `accept()` (talk again = yes). Else build team, `top` level, `game.ui.ask({ text, yes: 'Battle!', no: 'Not now', onYes: accept, onNo })`. Text: wins 0 `Leader Rocco: Want a rematch? My team trained hard. Now they are up to level 11!`; wins ≥ 1 `Leader Rocco: Rematch number 3? You beat me 2 times! My team is up to level 14 now.`; onNo toast `Leader Rocco: OK! Come back any time.`. `pending = { npc, at: performance.now() }`. If `game.duels.incoming`, toast "Answer the battle question first!" instead.
- `accept()`: close box; only if npc still in `game.npcs.list`, `!npc.away`, `!game.inBattle`, `closedText` falsy, within `askRange`. Recompute team; `startBattle({ trainer: npc, team, intro, xpBoost: REMATCH.xpBoost, rematch: { gym: def.id, wins } })`. Intro: `def.rematchIntro` or wins 0 `['Back for a rematch? I have been training too!']` else `` [`Rematch number ${wins + 1}! My team got even stronger.`] ``.
- `won(npc, opts)`: `n = min(maxWins, wins + 1)`, save to `game.rematchWins`, `cubes += rematchCubes(n)`, sound `win`; toasts `${npc.name}: Wow, you beat me again!` and `Rematch win ${n}! +${c} Capture Cubes. Next time my team will be even stronger!` (if fully capped: `... My team can't get any stronger. You are the best!`).
- `lost(npc)`: toast `${npc.name}: Good battle! Train a little and try again.`
- `update()` every frame: close quietly if older than `askTime` s, further than `askRange`, npc away/closed, in battle, or not started.
- `close()`.
