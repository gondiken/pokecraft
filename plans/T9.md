# T9 · Four new types: Sky, Slime, Light, Paper (plan)

Owner's words: "4 more types pls: Sky, Slime, Light, Paper. they should all include similar amount of creatures
in them with the right evolutions, and some of them with their own attacks and animations of course ... I saw
that you've created a paper creature in this session [Origrane], so that can be part of the paper type; but
then we'd need another creature for where that was now placed."

Result: **23 types**, 87 → **107 moves** (+16 type moves, +4 signature moves), **161 normal species** (23 × 7;
+28 new: 27 for the new types + Puzzlet, Mind's new 7th) + Zenithar. Origrane keeps its id, name, model and
stats and becomes Paper. No gyms here (T10), no real attack animations (T11): T9 adds simple fallback
effects so the `fx` spec stays green until T11 replaces them. Ids below are final; T10/T11 rely on them.

**Effectiveness.** New rows:
```js
sky:   { fire: 2, paper: 2, pixie: 2, rock: 0.5, metal: 0.5 },
slime: { metal: 2, sky: 2, sound: 2, slime: 0.5, toxic: 0.5, paper: 0.5 },
light: { ghost: 2, slime: 2, cosmic: 2, light: 0.5, rainbow: 0.5, paper: 0.5 },
paper: { rock: 2, slime: 2, light: 2, fire: 0.5, metal: 0.5, paper: 0.5 },
// added to existing rows (new defenders):
normal:   { ..., slime: 0.5 },              // bumps bounce off jelly
fire:     { ..., paper: 2 },                // paper burns
grass:    { ..., slime: 2, sky: 0.5 },      // plants soak up goo; leaves just blow away
electric: { ..., sky: 2, light: 0.5 },      // lightning strikes flyers; bulbs love electricity
rock:     { ..., slime: 0.5, paper: 0.5 },  // rocks sink into goo; paper wraps rocks
ice:      { ..., sky: 2 },                  // frozen wings
bug:      { ..., sky: 0.5 },                // bugs get blown away
metal:    { ..., paper: 2 },                // scissors cut paper
toxic:    { ..., light: 2 },                // smog hides the sun
pixie:    { ..., light: 0.5 },              // sparkles don't dim light
cosmic:   { ..., light: 2 },                // black holes gobble up light
```
Kid reasons (README/Book): **a four-way circle**: *wind blows paper away* (sky > paper), *paper is a lampshade
that blocks the light* (paper > light), *sunshine dries up slime* (light > slime), *sticky slime glues wings*
(slime > sky). Plus: sky blows out flames and blows little pixies around; slime gunks up metal gears and
muffles sound; light chases away ghosts and outshines the stars; **paper covers rock** (like the hand game),
and soaks up slime like a paper towel. Weak spots: sky ← electric, ice, slime; slime ← grass, light, paper;
light ← toxic, cosmic, paper; paper ← fire, metal (scissors), sky.

Balance (measured with a script over all 23 types): each new type hits 3 types hard, is weak to 3, resists 2-4.
Existing types gain at most one weakness: fire (3), pixie (3), metal (3), sound (3), cosmic (3), toxic (3);
**ghost and rock go to 5 weaknesses** (same as drake today; see §8). Every pair the `bone-alien` spec and the
`new-types` triangle check is unchanged.

## 3. Weather (`weather.js` `BOOSTS`)
```js

```
No wind weather exists, so "windy" = storm. No fog boost for slime (measured: it would *lower* slime's share in a
foggy swamp, ×0.89, because ghost and bone get bigger boosts there). Measured with the §5 tables, all old rows
still pass: storm/plains electric ×2.85, rain/swamp water ×1.79, rainbow/meadow rainbow ×7.6 (share 17.8%),
fog/swamp ghost ×1.78, stars/peak cosmic ×1.47; new rows: rain/swamp slime ×1.49, rainbow/meadow light ×1.52,
storm/peak sky ×1.31, rain/plains paper ×0.53.
