# T21 · Two new types: Cozy and Treasure (plan)

Owner's design (ROADMAP "Waves 7 and 8", T21): like T18 (colours, chart, moves, fx, sound, wool, README, Book), 7
creatures per type (three 2-stage families + one single, **one new body shape per family**), **no new battle
mechanics**. Both types are found **only near a finished home of their type** (T22 builds homes), as one more spawn
condition in T18's system. Treasure creatures **sparkle all the time** and are **rare**.

Result: **28 types**, 123 → **134 moves** (+9 type moves, +2 signature moves), **196 normal species** (28 × 7, +14) +
Zenithar, 16 signature moves, wool blocks **68 (cozy) and 69 (treasure)**, 8 new body shapes, one new spawn condition
`home:<type>`, a generic "sparkle" on every Treasure model. `duel.js` `VERSION` 6 → **7**. No new module, no new sound
apart from `fx:cozy` / `fx:treasure`. Until T22 exists nobody provides homes, so these 14 creatures **never spawn**
(by design); the new spec drives the condition with fake homes.

Files: `species.js`, `shapes.js`, `spawnrules.js`, `creatures.js` (2 small hunks), `book.js` (spawnInfo), `main.js`
(1 line), `blocks.js`, `fxrecipes.js`, `fx.js` (`BITMAPS` additions only), `sound.js`, `duel.js`, README, CLAUDE.md,
specs. Never touches `world.js`, `gymplace.js`, `gyms.js`, `npc.js`, the guide or access.

### 5.1 Sparkle: every Treasure creature twinkles (in `species.js` + one helper in `shapes.js`)
One rule for the whole type (like "Camo creatures wear a disguise"): `buildModel` adds it when `sp.type ===
'treasure'`, so it is also in battles, the Book, portraits and the play-together lead model.

`shapes.js` (exported helper): a glint = two crossed flat 4-point stars in one geometry (16 triangles, one mesh):
```js
// A twinkle: two crossed flat four-pointed stars (one mesh, 16 triangles).
export function sparkleGeometry(r) {
  const q = r * 0.16, pos = [];
  const tips = [[r, 0], [0, r], [-r, 0], [0, -r]], ins = [[q, q], [-q, q], [-q, -q], [q, -q]];
  for (const plane of [(a, b) => [a, b, 0], (a, b) => [0, b, a]]) {
    for (let i = 0; i < 4; i++) {
      pos.push(...plane(0, 0), ...plane(...ins[(i + 3) % 4]), ...plane(...tips[i]),
               ...plane(0, 0), ...plane(...tips[i]), ...plane(...ins[i]));
    }
  }
  const g = new THREE.BufferGeometry();
  g.setAttribute('position', new THREE.Float32BufferAttribute(pos, 3));
  g.computeVertexNormals();
  return g;
}
```
`buildModel` (species.js), **after** the `parts.float` block (so glints stay opaque) and before `root.scale`:
```js
  // Treasure creatures sparkle all the time: three glints twinkle in turn at spots around the body.
  if (sp.type === 'treasure') {
    const bb = new THREE.Box3().setFromObject(root);
    const c = bb.getCenter(new THREE.Vector3()), size = bb.getSize(new THREE.Vector3());
    parts.sparkle = [];
    for (let k = 0; k < 3; k++) {
      const mat = new THREE.MeshLambertMaterial({ color: 0xffffff, emissive: new THREE.Color(0xfff2b0), side: THREE.DoubleSide });
      const g = new THREE.Mesh(sparkleGeometry(0.16), mat);
      const spots = [0, 1, 2].map(j => {
        const a = k * 2.1 + j * 2.4, h = 0.3 + 0.25 * ((k + j * 2) % 3);
        return new THREE.Vector3(c.x + Math.sin(a) * (size.x / 2 + 0.04), bb.min.y + size.y * h, c.z + Math.cos(a) * (size.z / 2 + 0.04));
      });
      g.position.copy(spots[0]);
      root.add(g);
      parts.sparkle.push({ g, spots, phase: k * 0.55, period: 1.5 + k * 0.3 });
    }
  }
```
Each glint has its own material (so `disposeModel` and `tintModel`, which uses `emissive`, need no change; Lambert, not
Basic, because `tintModel` reads `material.emissive`). At build time all three glints show at full size (portraits and
the Book show the sparkle). `animateModel`, one loop, **no allocation** (only `copy`/`setScalar` on existing objects):
```js
  for (const s of p.sparkle || []) {
    const u = (t + s.phase) / s.period, n = Math.floor(u);
    const k = ((u - n) * s.period) / 0.45; // each twinkle lasts 0.45 s of its period
    const a = k < 1 ? Math.sin(k * Math.PI) : 0;
    s.g.visible = a > 0.03;
    if (!s.g.visible) continue;
    s.g.position.copy(s.spots[n % 3]);
    s.g.scale.setScalar(a);
    s.g.rotation.z = k * 0.8;
  }
```
(`t` is never negative in callers; use `((n % 3) + 3) % 3` to be safe.) Cost: 3 small meshes per Treasure creature,
at most 1-2 visible at a time.

## 6. Spawning: the `home:<type>` condition (data only; T22 provides the homes)

### 6.1 `spawnrules.js`
```js
// T21: Cozy and Treasure creatures only come to a finished home of their type. Homes come from creatures.env.homes()
// (T22). A home is { type, x, y, z, full, spawnSpot() }: x/y/z = its Doormat, full = every feature done (a cozy
// home's 5 hearts), spawnSpot() = a free cell { x, y, z } (integers, y = the air cell above the floor) in or right
// by the home, or null. Only homes within HOME_RANGE of the player count.
export const HOME_RANGE = 32;
// 16:00-22:00 on the HUD clock (game.time 0 = 06:00, 1 = a whole day).
export const isEvening = time => { const t = ((time % 1) + 1) % 1; return t >= 10 / 24 && t < 16 / 24; };
// Share of spawn attempts (one every 0.6 s) while near such a home and none of its creatures is out; T22's HomeType
// may point at these. evening / full multiply the share.
export const HOME_SPAWN = {
  cozy: { share: 1 / 60, evening: 1.5, full: 2, toast: 'Knock knock! A cozy creature came to visit your home.' },
  treasure: { share: 1 / 1500, toast: 'Something is sparkling at your home... a treasure creature!' },
};
const homeOf = (c, type) => c.homes?.find(h => h.type === type);
```
and in `CONDITIONS`:
```js
  home: {
    ok: (c, type) => !!homeOf(c, type),
    share: (c, type) => {
      const s = HOME_SPAWN[type] || {};
      return (s.share ?? 0) * (c.evening ? s.evening ?? 1 : 1) * (homeOf(c, type)?.full ? s.full ?? 1 : 1);
    },
    max: 1,
    place: (c, type) => homeOf(c, type)?.spawnSpot?.() ?? null, // where it appears (instead of a random spot)
    text: type => `near a ${type} home`,
    toast: type => HOME_SPAWN[type]?.toast,
  },
```
